# 协议兼容矩阵

对照基准：`Silent1566/webhtv`（FongMi/CatVod 生态）。
本矩阵记录**上游能力 → 本项目实现 → 支持状态**，支持状态取值：✅ 完整 ｜ ⚠️ 部分 ｜ ❌ 不支持（含原因与降级行为）。

## 一、配置与网络规则

| 上游字段 | 本项目实现 | 状态 |
| --- | --- | --- |
| `spider` / `sites` / `parses` / `lives` | `SourceConfig` | ✅ |
| `doh` | `DohConfig`（模型已就绪） | ⚠️ 解析器（自定义 `URLProtocol`）未做 |
| `proxy` | `ProxyRule` + `ProxyRuleResolver` / `ProxyEndpoint`（非通配优先、本地地址直连、账号密码解析） | ⚠️ 选择已就绪；真正走代理的会话池（HTTP/SOCKS + 认证）未做 |
| `hosts` / `headers` | `SourceConfig.hosts` / `HeaderRule` + `HostRuleMatcher`（与 `proxy`/`rules` 共用同一套 host 匹配语义） | ⚠️ `headers[]` 注入已生效（URLSessionTransport）；`hosts` 覆盖与 `doh` 同批未做 |
| `rules` / `ads` | `SniffRules` 复用同一套规则（`exclude`→`regex`→默认媒体正则）；`ads` 在传输层拦截 | ✅ M05c / M6 生效 |

| 相对路径以配置文件为基准 | `ConfigLocator.resolveURL(_:relativeTo:)` | ✅ |
| `msg` 非空视为错误响应 | `SourceConfig.isErrorResponse` | ✅ |
