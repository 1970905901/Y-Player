# M07d-8 节目单跟着时间走（直播页的「正在播」不再冻住）

- 状态：**已实现**（`LiveClock` + 直播页与节目单弹层各挂一次；新单测）
- 时间：2026-10-10
- 触发：节目单的「正在播 / 未开始 / 可回看」都是**按时间算的**（`LiveListLayout` 吃 `at: now`），
  而 `body` 只在该视图的**被观察状态**变化时才重算 —— 预取队列跑完后没有状态再变，
  行上的时间就冻住了：19:30 过后还写着 19:00 那档是「正在播」，列表在说假话。

## 一、做法：整分钟对齐的时钟

`LiveClock`（`LiveClock.swift`）：

- `secondsUntilNextMinute(from:)`：距离下一个整分钟的秒数（正好在整分钟上给 **60**，不给 0 —— 0 会空转）；
- `LiveClockModifier` / `.liveClock($now)`：用 `.task` 循环，**睡到下一个整分钟**再写回绑定
  （多睡 50ms，别在边界上读到上一分钟）；视图消失（切走 Tab / 关掉弹层）时随视图取消，不留孤儿定时器。

为什么是整分钟：节目按分钟切，30 秒刷一次没有意义；对齐后每分钟只重算一次。

挂了两处：

- `LiveView`：`rows` 从「现算 `Date()`」改成读状态 `now`，`content` 上挂 `.liveClock($now)`；
- `LiveScheduleView`（弹层）：`programRows(..., at: now)` 同样吃状态 —— 弹层开着跨过边界时，
  「正在播 / 可回看 / 未开始」跟着换。

## 二、测试

`LiveClockTests` 3 条：正好在整分钟（给 60）、半分钟处（30）、差半秒（0.5，不跨边界）。
