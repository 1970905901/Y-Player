## 一、为什么补这个

M07d-3 的换台只在**当前分组内**环形。一个分组几十上百个频道时这够用，但实际用起来还缺两件事：

1. **「跳到下一个分组」** —— 源把频道按「央视 / 卫视 / 地方…」分好组，跨组是常用动作，
   而 M07d-3 在组边界只能绕回本组第一个；
2. **「直接输频道号」** —— 解析时给每个频道补了 `001`、`002`…（上游也这样），
   用户看到的就是号；没有输入入口的话，找「8 台」只能靠滚。

## 二、落地了什么

| 件 | 说明 |
| --- | --- |
| `CatVodCore/Vod/Live/LiveChannelTarget.swift` | 换台目标（分组 + 频道）—— 跨组与跳号都可能换组，所以不能只带频道 |
| `LiveChannelNavigation.across(in:groups:step:)` | 跨组：往后取邻组**第一个**可播频道、往前取邻组**最后一个**；跳过整组不可播的分组；一圈都没有就回到当前分组的边界频道 |
| `LiveChannelNavigation.channel(number:in:)` | 按号跳：分组顺序、组内顺序取第一个命中；两边能解析成整数就按整数比（`001` 与 `1` 等价），否则字符串相等；空串 / 非数字 / 找不到 → `nil` |
| `CatVodUI/LiveChannelJumpView.swift` | 「按号码跳台」页：输入 + 「跳台」+ 找不到时的一句说明；**不碰播放**，找到就回调给播放页 |
| `CatVodUI/LiveView.swift` 的播放页 | 右上角新增**频道菜单**（上一个 / 下一个分组、按号码跳台…）；播放页的输入从「一份频道列表」改成「分组列表 + 分组名」，重建键也带上分组 |
| 单测 | `LiveChannelNavigationTests` +4 例（跨组三个方向与跳过空组、单组/未知组/全不可播、按号整数比较与顺序、坏输入） |

## 三、逐条对比与差异

| 上游 | 本仓库 | 差异 |
| --- | --- | --- |
| `across`（跨组动作） | `across(in:groups:step:)` | 上游那个动作的具体定义**不在本地取到的源码里**，所以「走到邻组边界频道、跳过整组不可播、一圈回到当前组」这三条是**本项目定的**，理由写在函数注释里并由测试钉住 |
| `findByChannelNumber`：`Integer.parseInt` + 逐组 `find(num)`，未命中返回 `{-1,-1}` | `channel(number:in:)` | 语义一致；差异在坏输入：上游在非数字上会**抛异常**，我们返回 `nil`（界面给一句「没有这个频道号」） |
| 频道号来自解析时补的 `001`、`002`…（`LivePlaylistParser`） | 同 | 两边能解析成整数就按整数比，所以 `8` 能命中 `008` |
| — | 跳号页不做数字键盘 | `.keyboardType` 是 iOS 专有，业务视图不写平台分支（`docs/UI 规范.md`）；纯输入框两端一致 |
| — | 换台范围 = **分组条上看得见的那几组** | 锁着的加密分组不在里面（M07d-4）：跳号与跨组都不会把你带进没解锁的组 |

另两条实现上的取舍：

1. **播放页的状态从「频道列表」改成「分组列表 + 分组名」**：跨组换台要换分组，而分组列表才是稳定的那份
   （列表行只是它的投影）。重建键从「频道 + 线路」扩成「分组 + 频道 + 线路」—— 两个分组里同名频道不会串。
2. **跨组 / 跳号与组内换台共用同一条落地路径**（`move(to:)`）：改分组与频道、线路归零、写回 keep、
   拉新频道节目单 —— 三处入口只有一套行为，不会各自漏一件事。

**未做**：频道的「最近观看」列表、分组内的快速字母索引（上游没有，暂时不需要）。

## 四、验收

- 本机自检：`check_swift.py` + `scan_report.py`（0 条真问题）、行长与注释空格自查。
- CI：**本轮未盯**（按约定攒着一起看）。新增的是 Core 纯逻辑用例 + 一个输入页 + 一个菜单，
  风险面同 M07d-3/-4（要么 SwiftPM 编译，要么 `Build apps` 的 iOS 15 下限）。
- 人工（需真机 / Mac）：
  1. 播放任意频道 → 右上角「频道」菜单里有「下一个分组 / 上一个分组 / 按号码跳台…」；
  2. 「下一个分组」跳到下一组的**第一个**频道；「上一个分组」跳到上一组的**最后一个**；
  3. 到了最后一个分组再点「下一个分组」→ 回到第一个分组（循环）；
  4. 加密分组锁着时，跨组会跳过它（不会跳进没解锁的组）；只有一个分组时两个菜单项置灰；
  5. 「按号码跳台…」输 `8` → 跳到号 `008` 的频道；输不存在的号 → 留在原页并给出说明；
  6. 换台 / 跨组 / 跳号之后退回列表：「继续观看」是刚跳到的那个频道（keep 跟着走）。
