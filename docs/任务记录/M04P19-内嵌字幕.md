# M04P19 内嵌字幕（文本轨出字）

- 状态：**已实现**（本地静态闸门全绿 + 新单测；Mac 编译 / 测试 / 上机待 YG）
- 时间：2026-10-10
- 触发：M04 线**最后一个功能缺口** —— 容器里带的字幕轨以前连清单都不报（界面不显示字幕选择）；
  MPV 内核那条早就有了（mpv 自带 libass）。

## 一、做法

1. **只报文本轨**（`LibavSubtitleDecoder.isTextCodec`）：subrip / ass / ssa / mov_text / webvtt / 纯文本…
   位图轨（`hdmv_pgs_subtitle` / `dvd_subtitle` / `dvb_subtitle` / `xsub`）**连清单都不报** ——
   给一个「选了也出不了字」的选项，比不给更坏。
2. **默认轨跟 MPV 的 `sid=auto` 一个口径**：优先容器标了 `AV_DISPOSITION_DEFAULT`（0x1）的那条，
   没有就第一条能出字的；开不了**不拦路**（字幕是锦上添花，没它也能播）。
3. **只出字**：`avcodec_decode_subtitle2` → `AVSubtitle` 的文本 / ASS rect → ``SubtitleCue``；
   ASS 覆盖标签 `{\pos(1,2)}` 一律剥掉、`\N` / `\h` 还原成换行 / 空格（纯函数，可单测）。
   **样式不还原**（字体 / 位置 / 卡拉OK）—— 那是 libass 的活；播放页现成的 `SubtitleOverlay` 只画文本。
4. **时间口径**：`start/end_display_time` 是**相对包时间**的毫秒；结束时间缺失（`UInt32.max`）或 ≤ 起点时
   给 4 秒兜底 —— 不猜「显示到下一句」（那要往后看，而这条路是边读边出的）。包时间 pts 优先、
   没有用 dts、**都没有就丢这一条**（宁可不显示，也不错位到 0 秒）。
5. **整份替换语义**（跨层）：会话每次发**全量** cue 列表（空数组 = 清空 / 关掉），播放页整份替换；
   选了内嵌轨时**内嵌优先于外部字幕**（「选了内嵌轨」就是「我就要这个」）。
6. **换轨走解码线程**（与换音轨同一套）：新解码器先建好、成了才换；换完清空旧 cue 再让新轨慢慢解。

## 二、口径与已知取舍

- v1 **只出字**：ASS 样式不还原、位图轨不做、没有内核级的「字幕延迟」这类调整
  （字号 / 位置归播放页的显示设置）。
- 内嵌 cue 与外部字幕文件**不混着显示**：选了内嵌就用内嵌那份；关掉内嵌回到外部那份。
- 清单里只有流下标（没有语言 / 标题）—— 与音轨一致，v1 不装。

## 三、故意没做

- libass 渲染（样式还原、位图轨）；
- 字幕轨的语言 / 标题展示；
- 字幕的乱码兜底（编码探测）：按容器 / 解码器给的文本来，不猜。

## 四、验证点（Mac）

1. `swift test --package-path Packages/CatVodPlayer`：新套件「内嵌字幕解码」3 条
   （编码白名单 / ASS 加工 / 包时间）；真会话两条补断言（夹具没有字幕轨 → 清单为空；
   关字幕是安全空操作）；
2. 全包测试 + App 编译照旧；
3. **上机**：播一个**带内嵌字幕**的本地 mp4 / mkv（站点流一般没有内嵌轨）→ 播放页出现「字幕」选择 →
   默认就该出字；换轨 / 关闭都该有反应（关闭后回到外部字幕或没有字幕）。

## 五、教训（写给下一次）

- **internal 方法不能拿 private 类型当签名**：`PendingSubtitleTrack` 是 private 嵌套枚举，
  两个用它当参数 / 返回值的方法必须是 `private`（同文件扩展里的 `private` 成员照样能被主声明调用 ——
  这一点在 M11 拆 `VodDetailView` 时已经验过）。换音轨那两个方法当年是 private 所以没事，
  新写的字幕这两个忘了带 —— 一红就是四条。
- 反过来的坑也记着：**跨文件**的成员不能带 `private`（`VodDetailView+Emby`、`PlaybackView+Overlays`
  那两处就是这么改的）。同文件扩展 vs 跨文件扩展，visibility 的规矩正好相反，写完先想一句「它在哪个文件」。

## 六、留给后面的

- 位图轨（PGS / DVD）：要自己画图，是另一条链的活；
- ASS 样式：libass；
- 字幕 / 音轨的语言与标题：清单得再带一层元数据。
