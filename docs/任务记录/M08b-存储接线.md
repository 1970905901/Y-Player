## 二、设计取舍

1. **只替换构造**：`favoriteStore` / `progressStore` 是 `FavoriteStore` / `PlaybackProgressStore` 协议类型，
   详情页、追剧页、播放页一行都不用改 —— 这正是 M2/M02P8 当初把协议抽出来的目的。
2. **打开失败必须能降级**：磁盘不可写、库损坏时退回内存实现，并在设置页写明「本次运行不会记忆」；
   宁可这一轮不记忆，也不能让详情页/追剧页打不开。
3. **库路径固定**：`Application Support/YPlayer/YPlayer.sqlite`（与源缓存同级目录），不放进 Caches：
   Caches 会被系统回收，收藏与进度不能被回收。
4. **失败可见**：`StorageFailureRecorder` 的最近失败在设置 → 数据 → 缓存管理里直接列出。
