# M03P17 播放页换线路（对齐上游播放页的线路条）

- 状态：**已实现**（本地静态闸门全绿 + 新单测；Mac 编译 / 测试 / 上机待 YG）
- 时间：2026-10-10
- 触发：线路不稳是这类站点的常态 —— 现在换线路要「退回详情页 → 换线路 → 重新点那一集 → 再拖回原处」。
  上游播放页自带一列线路条（`mBinding.flag` + `FlagAdapter`：点一条就 `mVod.selectFlag(item)`）。
- 依据：`VideoActivity`（`mFlagAdapter` / `mVod.selectFlag`）、`VodPlaybackController.selectFlag` +
  `seamless()`（换线路时按**集名**在新线路上找同一集继续播）。

## 一、上游口径 → 本项目

| 上游 | 这里 |
| --- | --- |
| 播放页一列线路条，点一条换一条 | 播放页信息区「线路」Picker（`PlaybackLineSwitcher` + `PlaybackView+Lines.swift`） |
| `selectFlag` → `seamless()`：按集名找同一集，找到就播 | `PlaybackLineSwitcher.matchIndex(episodeName:index:names:)`：**先按集名**，名字对不上再按下标兜底，越界给 nil |
| 换线路不动「看到第几集」 | 集下标 + 集名一起传给详情页的取地址闭包；换完就地重载（同一个引擎） |
| 位置接着看 | 换之前先 `persist(force: true)`，换完 `resumableResource()` 按进度记录续播（≤5 秒误差） |
| 换不成（那条线上没有这一集） | 如实提示「「线路名」上没有找到这一集，换线路没成」并**留在原线路**，不硬编地址 |

## 二、口径与取舍

- **只有一条线路不显示**（详情页直接给 `nil`）；
- **详情页的线路选择跟着换**（`onLineChanged`）：从播放页返回时停在刚看的那条线上；
- **换线路与换集共用一个落点**：`applyEpisode`（M12P1 的 switchEpisode 抽出来的共同部分）——
  清界面状态、同一个引擎重新 load；取地址的规则也只有一份（`VodDetailView.episodeResource(for:at:)`）；
- **拿不到线路清单的路不显示线路区**：解析链（`ParsePlaybackView`）、直播 —— 与「不摆假菜单」一致。

## 三、故意没做

- **「换源」也搬进播放页**（同名条目跨站切换）：那是另一条链（换的是站点不是线路），详情页已经有了；
  要搬得先把「跨站换集」的集身份对齐语义定清楚，留给后面；
- **线路测速 / 自动选最快线路**：上游没有，不做；
- **换线路时保留引擎缓冲**：换线路 = 换资源，重新 load 最省事（与换集一致）。

## 四、验证点（Mac）

1. 一部多线路的片 → 播放页信息区出现「线路」（只有一条线路时不出现）；
2. 播到 5 分钟 → 换另一条线路 → **接着从 5 分钟左右继续播**（不是从头），标题与选集下标不变；
3. 换到没有这一集的线路 → 顶部提示「…上没有找到这一集」，仍停在原线路；
4. 从播放页返回详情页 → 详情页的「线路」停在刚看的那条线上。
