# M03P2 实机验证清单（不需要 Mac）

- 状态：**待你在设备上执行**；CI 侧前置条件已就绪（`build.yml` 的 `ipa` 作业每次推送产出未签名 IPA）
- 为什么走这条路：模拟器能验正确性但慢且数字不能代表设备；**实机是唯一能给出真实性能与观感的方式**，
  而侧载不需要 Mac。

## 一、拿到 IPA

1. GitHub 仓库 → **Actions** → 最新一次 `build` 运行（作业名 **Unsigned IPA (sideload artifact)**）；
2. 该运行页面底部 **Artifacts** → 下载 `YPlayer-unsigned-ipa`；
3. Windows 上安装 **Sideloadly**（或 AltServer for Windows）→ 连数据线 → 拖入 IPA → 填 Apple ID → Start；
4. 设备上 **设置 → 通用 → VPN与设备管理** → 信任你的开发者证书；
5. 免费 Apple ID 的证书 **7 天**过期，过期重跑一次第 3 步即可。

## 二、上去之后按顺序看这 6 件事

| # | 看什么 | 期望 | 不符合时怎么办 |
| --- | --- | --- | --- |
| 1 | App 能否**启动** | 能进主界面 | 秒退多为 `dyld` 缺库（重签时 `NodeMobile.framework` / MPVKit 的 dylib 没被签上）。**无 Mac 也能查到**：设置 → 隐私与安全性 → 分析与改进 → 分析数据，找名字含 `YPlayer` 的日志，把开头几十行发我（会直接写明缺哪个库） |
| 2 | 接口页填 `https://9280.kstore.vip/ceshi/index.js` **或** `…/index.js.md5` → 加载 | 「状态」显示 JS 源（js2p）+ 摘要 | 失败信息会显示在「加载失败」区块，原样发我。**两种填法都合法**：参考实现（webhtv）就是让用户填 `index.js.md5`，我们在 `ConfigLocator` 里归一化成 `.js` 下载；`index.js` 与 `index.js.md5` 会落到同一份缓存 |
| 3 | 「Node 宿主」区块 | `宿主运行中：http://127.0.0.1:<port>，站点 85 个…` | ① 显示「不可用」→ 点**查看宿主输出**发我；② 一直停在「正在启动宿主并拉取站点…」→ 把「查看宿主输出」里的内容发我，**尤其是 `--- 落盘日志尾部 ---` 那几行**（预载脚本会把致命错误和缺失的核心模块写进去，2026-10-07 加的） |
| 4 | 「站点」清单 | 约 **85** 个站点 | 数量差很多也发我（可能上游配置变了） |
| 5 | 首页/搜索选一个站点 | 能出内容（走 CatSpider HTTP 协议） | 报错原样发我（`CatVodError` 会带状态码与原因） |
| 6 | 详情 → 选一集 | JS 源站点会先请求播放地址再进播放页；失败给可读原因 | 同上 |

**顺带一条现场验收**：设置里的播放内核若选 **MPV**，应当**如实显示不可用**（引擎尚未实装）。
若它显示"可用"却播不了，那就是我在 CI 里刚修掉的那类"谎报可用"问题又出现了 —— 请立刻告诉我。

## 三、请回传的信息（有这些我就能定位）

- 设备型号 + iOS 版本；
- 上面每一表的实际现象（截图或文字都行，**「Node 宿主」区块的输出最关键**）；
- 若涉及性能：粗略感受即可（宿主从开始加载到出现站点约几秒、首页首屏约几秒）——**设备上的数字才算数**，模拟器的数字我不会拿来当结论。

## 四、已知边界（提前说清，避免误判）

- **内嵌 node 是「进程内嵌」**：宿主里一旦出现无法挽回的致命错误，**App 可能直接退出**（不是普通报错）。
  这是 nodejs-mobile 的固有性质，不是界面 bug。2026-10-07 起已加预载脚本缓解：
  它会拦截 `process.exit`/未捕获异常并把现场写进宿主日志，所以**若遇到闪退，请再进一次
  「接口管理 → Node 宿主 → 查看宿主输出」，把 `--- 落盘日志尾部 ---` 那几行发我**；
- **MPV / FFmpeg 内核尚未实装**：现在能播的是"直链且无需解析"的集（系统播放器）+ JS 源站点的 `POST /play` 结果；
  需要解析（`parse/jx = 1`）的集属 M5；
- **免费证书 7 天**：过期是证书问题，不是 App 问题；
- 首次进详情/播放会比后续慢（详情缓存首次未命中）。
