# M03P16 片头 / 片尾（对齐上游 `opening` / `ending`）

- 状态：**已实现**（本地静态闸门全绿 + 新单测；Mac 编译 / 测试 / 上机待 YG）
- 时间：2026-10-10
- 触发：上游播放页的动作栏里有一对「片头 / 片尾」（`control.action.opening/ending`），我们一直没有 ——
  追剧时每集都得手动拖过片头，片尾也不会提前跳。
- 依据：`VideoActivity.onOpening/onEnding`（标记与「重置」）、`PlayerManager.canSetOpening/canSetEnding`、
  `Constant.getOpEdLimit`、`VodHistoryPolicy.startPositionMs`、`VodPlaybackController.onTimeChanged`
  （片尾跳集）、`History.opening/ending`（存哪）。

## 一、上游口径 → 本项目

| 上游 | 这里 |
| --- | --- |
| `opening` = 标记时的**当前位置**；`ending` = `duration - 标记时的位置` | `PlaybackProgress.opening` / `.ending`（秒）——与进度同一条记录；GRDB 迁移 `v4.playbackOpeningEnding` 加两列 |
| 只能在两端附近标（`getOpEdLimit`）：<15 分钟 → 3 分钟、<30 分钟 → 6 分钟、其余 → 10 分钟 | `PlaybackOpeningEndingRules.limit/canSetOpening/canSetEnding`（纯函数，有单测）；不在范围里按钮置灰 |
| 起播位置 `max(opening, position)`（`VodHistoryPolicy.startPositionMs`） | `PlaybackOpeningEndingRules.startPosition`；提示条把「跳过片头」与「续播」分开说 |
| `ending > 0 && position + ending >= duration` → `nextEpisode(false)` | `.timeChanged` 里 `skipEndingIfNeeded` → 走既有的 `switchEpisode`（M12P1）；`didSkipEnding` 保证一集只跳一次 |
| 标记入口在控制条：tap 标、长按清 | 播放页信息区「片头 / 片尾」两行：没标 →「标记当前」（不在可标范围里置灰）；标了 → 时间 +「清除」 |
| 存 `History` | 存 `PlaybackProgress`（与进度同一条记录，一部片一集一条） |

## 二、口径与取舍

- **直播不显示这一区**：直播没有时长也没有进度记录 —— 门槛是 `activeProgressContext != nil && duration > 0`；
- **最后一集不跳**：没有下一集就停在结束态（与 M12P1 的片尾策略一致）；
- **标记绑在「片源 + 集」上**：换集读的是新那集的记录，不会串（`resumableResource()` 里先清零再读）；
- 上游长按按钮 = 清除，我们做成显式的「清除」按钮 —— iOS 上长按还要跟手势层抢，不划算；
- **与上游的一处微差**：`canSetEnding` 比上游多一道「至少还剩一点」（`tail > 0`）——
  上游在最末尾标出来的是 0，而 0 在两边都是「没标」：那一下等于「点了没反应」，我们直接不给标（有单测钉着）。

## 三、故意没做

- **片头 / 片尾的 ±1 秒微调**（上游 leanback 用遥控器左右键）：手机上没有对应交互；
- **自动识别片头片尾**（音频指纹那类）：上游也没有，不做；
- **片尾跳集前的倒计时提示**：直接跳（上游也是直接 `nextEpisode`）。

## 四、验证点（Mac）

1. 追一部有片头的剧：播到片头结束处 → 信息区「片头」点「标记当前」→ 该行变成 `01:23`；
2. 退出播放页再进（或杀掉重开）→ 片头标记还在，且**开播直接跳到 01:23**（提示「已跳过片头」）；
3. 拖到离片尾 2 分钟 → 「片尾」点「标记当前」→ 播到那儿**自动进下一集**；
4. 离片尾还很远时「标记当前」是灰的（可标范围：<15 分钟片 3 分钟、<30 分钟 6 分钟、更长 10 分钟）；
5. 点「清除」→ 标记消失，再进从头播（只按续播位置走）。
