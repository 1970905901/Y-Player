## 重要修正记录

1. **`CodingKeys` 三类坑**（会导致编译失败，已全部修掉）：
   - 两个 case 映射同一 raw value（`PlaybackURLs.Entry`）；
   - 别名 case 不对应任何存储属性（`Site.homePage`、`VodCategory`、`LiveSource.ua`、`SubtitleSource`）；
   - 键名与属性名不一致时未用自定义 raw value（`VodFilter.initialValue = "init"`）。
   统一改为「精确 CodingKeys + 独立别名容器」模式。
2. **`page` 类型**：CatSpider 的 `page` 是整数，发字符串会让 JS 源分页判断失效（`CatSpider.java` 用 `addProperty("page", int)`）。
3. **`JSONSupport` 无限递归**：同签名重载会自我调用，已移除。
4. **`MediaFormatSniffer` 下标越界**：改为 `lowered.startIndex..<cutoff`。
