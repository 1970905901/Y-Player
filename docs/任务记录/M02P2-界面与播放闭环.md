# M02P2 界面层与最小播放闭环

- 状态：进行中（等待 CI 验证）
- 时间：2026-10-07
- 范围：`Packages/CatVodUI`（界面）、`Packages/CatVodPlayer`（系统内核导出）

## 目标

把 M1/M2 已完成的协议与传输层接成可用的界面闭环：
**接口管理 → 首页/分类/筛选 → 详情/线路/选集 → 播放**，并严格遵循 UI 版本自适应约定。

## 产出

| 文件 | 作用 |
| --- | --- |
| `AppModel.swift` | 主状态：配置地址持久化、加载状态机、站点清单、告警、播放内核偏好与降级原因、按配置构造传输层（带 `headers`/`ads`） |
| `InterfaceManagementView.swift` | 接口管理：加载/强制刷新、状态摘要（类型/站点数/缓存/离线回退/摘要）、告警、站点清单（含不可用原因）、播放内核选择 |
| `HomeView.swift` + `HomeView+Data.swift` | 首页：站点、分类、上游筛选项、内容列表、分页；非 CMS 站点与 JS 源给出明确提示 |
| `VodDetailView.swift` + `VodDetailView+Data.swift` | 详情：影片信息、线路、选集；可直链且 `parse=0` 的集直接播；其余进 `UnsupportedPlaybackView` 并说明原因 |
| `PlaybackView.swift` | 播放页：系统原生 `AVKit.VideoPlayer`、状态与错误展示、`teardown` 生命周期 |
| `AVPlayerEngine.systemPlayer()` | 向 UI 暴露系统播放器（M3/M4 换内核后改为导出渲染视图） |
| `RootView.swift` | 两个原生 Tab：「接口」+「首页」 |

## 关键设计取舍

1. **能力边界显式化**（不静默失败）：`parse/jx=1`、`type=4` 的 `play` 中转、Spider 站点都会渲染
   `UnsupportedPlaybackView`，写明原因与对应里程碑（M1.6 / M5 / 平台不支持）。
2. **UI 合规**：全部使用系统原生控件（`List`/`Picker`/`TabView`/`AVKit.VideoPlayer`），
   版本差异集中在 `Platform/`；未使用 `LabeledContent`（iOS 16+）等超出 iOS 15 的 API。
3. **状态与视图分离**：数据加载逻辑放在 `+Data.swift` 扩展里，便于后续单测与复用。

## 验收
