# M03P18 弹幕接通 + 总开关（顺手修「参数从来没人传」）

- 状态：**已实现**（本地静态闸门全绿 + 新单测；Mac 编译 / 测试 / 上机待 YG）
- 时间：2026-10-10
- 触发：做「播放页弹幕开关」时发现真问题 —— `PlaybackView` 的 `danmakuLines` / `danmakuDisplay` /
  `subtitleCues` / `subtitleDisplay` **四个参数从来没有任何宿主传过**，一直是默认值（空数组、
  默认配置）。也就是说：M08h 的上屏层、M08i 的显示设置、M09f 的字幕层都写好了，但**没接上管子** ——
  编译过、单测过、上机才会发现「怎么什么都没有」。

## 一、修的是什么

| 参数 | 谁传 | 之前 |
| --- | --- | --- |
| `danmakuLines`（弹幕行） | `model.danmakuLines`（M08c 起就躺在 `AppModel` 里） | 没人传 → 计划恒为 nil → 一层都不画 |
| `danmakuDisplay`（显示设置） | `model.danmakuDisplay` | 没人传 → 字号 / 透明度 / 速度 / 区域全部没生效 |
| `subtitleCues`（字幕 cue） | `model.subtitleCues` | 没人传 → 字幕层不存在 |
| `subtitleDisplay`（字幕显示设置） | `model.subtitleDisplay` | 没人传 → 开关 / 字号 / 位置 / 背景全部没生效 |

三处宿主（`VodDetailView` / `SitePlayEpisodeView` / `ParsePlaybackView`）都补齐；
`onStart` 里顺手把上一次的残留清掉（这两个数组在 `AppModel` 里是全局的，不清会串到下一部片）。

## 二、弹幕总开关（对齐上游 `DanmakuSetting.isShow`）

- `DanmakuDisplayConfig` 加 `isVisible`（默认开 = 不碰设置就等于 M08h 的行为）；
- 落盘形态从 4 段变 5 段（`字号|透明度|速度|区域|显示`），**4 段的旧值照样读**（按「显示」算，
  不把老用户的弹幕吞掉）；
- 渲染侧：关掉就**连计划都不排**（与字幕那层的 `subtitleDisplay.isVisible` 同一口径）；
- 入口两处：设置 → 播放 → 弹幕显示（一个 Toggle），播放页信息区（**只有这一集真有弹幕、
  且上层给了回写口**才出现 —— 不摆「这集本来就没弹幕」的假开关）。

## 三、换集 / 换线路时的字幕

换集（`applyEpisode`）会把**字幕时间轴与内嵌字幕 cue 清空**：外挂那份要上层重新取、
内嵌那份由新会话重新报 —— 宁可不显示，也不把上一集 / 上一条线路的字幕留在画面上。
**已知缺口**（下一步）：换集 / 换线路后没有人**重新取**那一份字幕（`PlaybackEpisodeResource`
只带资源，不带 `subs`）—— 要让新那集的 `subs` 跟着资源一起回来，才谈得上「切完还在」。

## 四、验证点（Mac）

1. 有弹幕的片（M08a 的取用链取到行）→ 弹幕**真的上屏**了，滚动连续、暂停会停；
2. 设置 → 播放 → 弹幕显示：改字号 / 透明度 / 速度 / 区域 → 屏上**跟着变**（以前改了没反应）；
3. 关掉总开关 → 整层消失；播放页信息区那个「显示弹幕」跟着变，返回设置页也一致；
4. 没弹幕的集：播放页**不出现**「弹幕」这一区；
5. 有外挂字幕的源（`subs`）→ 字幕**真的上屏**；改字号 / 位置 / 背景也跟着变；换集之后字幕先消失
   （不再串上一集的），这是已知缺口（第三节）。
