# M03P7 系统内核（AVPlayer）的轨道：多音轨 / 内封字幕可选

- 状态：**已实现**（本地静态自检过；真机由 YG 用 Mac 验证）
- 时间：2026-10-09
- 起因：M03P5 把 MPV 的轨道接上了，但**默认内核（系统播放器）**还是 `selectTrack` 空实现 ——
  「轨道」区只在选 MPV 时出现，多语言音轨 / 内封字幕在默认内核下切不了。

## 一、做法（`SystemPlayerEngine+Tracks.swift`）

| 事项 | 落点 |
| --- | --- |
| 上报列表 | `handleReady()` 之后 `reportTracks()` → `PlayerEvent.tracksChanged` |
| 音轨 | `AVMediaSelectionGroup(.audible)` 的 `options` 下标 |
| 字幕 | `AVMediaSelectionGroup(.legible)` 的 `options` 下标 |
| 画面轨 | 恒为 `[]`（没有切画面轨的需求，报了只会多出一排没人用的下拉框） |
| `auto` | `item.select(group.defaultOption, in: group)` |
| `disabled`（字幕「关闭」） | 仅当 `group.allowsEmptySelection` 才 `item.select(nil, in: group)`（音轨组一般不允许） |
| `index` | `item.select(group.options[index], in: group)`，越界直接不做 |

下标口径：**报出去的下标原样送回来能选中同一轨**（MPV 那边送的是轨道 id，两边各自自洽）。

## 二、故意没做

- **不与系统播放器自带菜单同步**：`VideoPlayer` 自己也有音轨/字幕菜单，用户在那儿改选之后，
  播放页「轨道」区的下拉框不会跟着变（要监听媒体选择变化通知，单独一片）；
- **不做画面轨切换**：系统内核下没这个需求；
- **不做重试**：条目没就绪 / 没有选择组时一律安全返回 —— 「什么都不做」比乱选一条好。

## 三、验证点（Mac）

1. 内核 = **系统播放器**，放一部**多音轨或带内封字幕**的片（mp4 / m3u8 常见）：
   - 播放页出现「**轨道**」区；
   - 切音轨 → 声音真的换语言；切字幕 → 字幕换语言 / 关闭；
2. 换一集 → 轨道区更新、选择回到「自动」；
3. 单轨片源：**不出现**「轨道」区（没有可选项，与设计一致）。

## 四、CI 能验到哪一步

- ✅ 能：编译 + **没有媒体时的边界**（列表为空、选择是安全空操作、越界下标不崩，
  见 `SystemPlayerTracksTests`）；
- ❌ 不能：「到底读出几条轨、切了有没有生效」必须真机/模拟器 —— 跑测试的机器上没有这种媒体
  （与 M02P15 里「不断言 `AVPlayer.rate`」同一条理由）。
