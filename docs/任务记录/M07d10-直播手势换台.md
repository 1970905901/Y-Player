- 状态：**已实现**（本地四闸门全绿 + 新单测；Mac 编译 / 测试 / 上机待 YG）
- 时间：2026-10-10
- 触发：M07d-3 / M07d-6 两处留口 ——「手势换台与 `invert` 开关不做」。当时给的理由是
  「播放页是系统 `AVKit.VideoPlayer`，手势面归它」；这条**已经过期**：自绘内核（MPV / 自研 FFmpeg）
  从 M03P6 / M03P12 起有自己的手势层，M03P23 的「一甩」判定（采样窗口 + 角度 + 起手区）正好能直接复用。
- 依据（上游 mobile）：`app/src/mobile/.../ui/activity/LiveActivity.java`
  （`onFlingUp`：`if (LiveSetting.isInvert()) nextChannel(); else prevChannel();`，`onFlingDown` 相反；
  那颗 `control.action.invert` 按钮 = `putInvert(!isInvert())`，选中态高亮）、
  `app/src/main/.../setting/LiveSetting.java`（`isInvert()` / `putInvert()`）。

## 一、上游口径 → 本项目

| 上游 | 这里 |
| --- | --- |
| `onFlingUp` → **上一台**、`onFlingDown` → 下一台（默认） | `LiveChannelNavigation.zapStep(swipeUp:invert:)`（纯逻辑）+ `PlaybackView.onVerticalSwipe` 回传 |
| `LiveSetting.isInvert()` 把两件事对调 | `AppModel.liveSwipeInvert`（键 `yplayer.liveSwipeInvert`，默认关 = 上游默认方向） |
| `control.action.invert` 那颗常驻按钮（选中态高亮） | 直播播放页工具栏第三颗图标（`arrow.up.arrow.down`，开着时用强调色） |
| 甩的判定在 `CustomKeyDown`（与点播同一个） | 同一套：M03P23 的 `PlaybackSwipeTracker` / `PlaybackSwipeRules`（0.15s 窗口速度 / 60pt / 70° / 起手在中间一半） |
| 甩的画面位移动画（`translationYBy(±24)`） | 不做（点播那边也没做；`invert` 在上游只影响它和方向，我们只留方向） |

## 二、口径与取舍

- **两个页面方向相反是有意的**：点播页「上滑 = 下一集」（上游 `VideoActivity.onFlingUp` → `nextEpisode`），
  直播页「上滑 = 上一台」（上游 `LiveActivity`）—— 这一批把 `PlaybackSwipeAction` 的 case 从
  `next` / `previous` 改名成 **`up` / `down`**（只报方向，含义由页面定），免得下一个人读到
  「上一台 = `.next`」发懵；
- **方向决策放在 Core**（`LiveChannelNavigation.zapStep`）：与 `neighbor` 同一个类型、同一组测试，
  界面那层只做 `swipe == .up` 的翻译；
- **只有自绘内核吃这套手势**（M03P6 起的规矩）：系统内核的画面区归 `VideoPlayer`，在它上面叠手势会打架 ——
  直播页用系统内核时没有纵甩换台（工具栏那两颗照旧，不受影响）；
- **到头了静默**：`zap` 找不到邻台（只有一个可播频道）时什么都不做 —— 与工具栏那颗置灰按钮同效；
  播放页那条提示条是点播换集用的（「已经是最后一集」），直播页不借它说别的事。

## 三、故意没做

- 甩的位移动画；`invert` 不作用于点播页（上游同：它只反转**直播**的滑动方向，点播那边只翻动画方向）；
- 上下滑换**分组**：跨组是上游的 `across` 动作，本项目已有菜单入口 —— 一个手势只表达一件事。

   与 `Packages/CatVodUI`（改名后那几条）；这一批只有改文件、没加删文件，**不用清 `.build`**；

3. **上机**（直播页，内核 = MPV 或自研 FFmpeg）：

   - **快速下滑** → 下一台；慢慢上下拖仍是音量 / 亮度；左右四分之一里的纵甩仍是音量 / 亮度；

## 五、教训

- **改 `PlaybackView` 的 init 是这轮的首验红点**（两条，本地闸门都抓不到）：实参顺序要跟声明一致
  （`onVerticalSwipe` 插在中间，调用点里的 `onPlaybackStats` 得往后让）；闭包参数里的
  `PlaybackSwipeAction` 必须 `public`（public init 不收 internal 类型）—— 详见交接文档坑列表第 22 条；
- 留口的**理由会过期**：M07d-3 写「播放页是系统 VideoPlayer，手势面归它」时是事实，
  自绘内核上来之后就不成立了 —— 每批开工前把留口原文读一遍，别拿旧结论当挡箭牌；
- 一个枚举被两个页面共用、而两页语义相反时，**名字要报「事实」（上 / 下）而不是「含义」（下一集）**：
  这次改名就是（`next` → `up`），不然直播那行读起来像 bug。
