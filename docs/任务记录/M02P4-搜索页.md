# M02P4 搜索页

- 状态：待 CI 验证
- 时间：2026-10-07
- 依赖：M2 的 `CMSClient.search`（客户端已实现）、M02P2 的首页/详情/播放闭环

## 范围

只走 CMS 通道（`type 0/1/2/4`）。`type=3` 的 JS/CatSpider 站点搜索依赖内嵌 Node 服务（M1.6），
页面明确提示「依赖内嵌 Node 服务」而不是静默返回空列表。

## 实现

| 件 | 说明 |
| --- | --- |
| `SearchView.swift` | 站点选择 + `.adaptiveSearchable` 搜索框 + 结果列表（复用 `VodRow`）+ 分页 |
| `SearchView+Data.swift` | `runSearch(targetPage:)`：关键词 trim、空关键词保护、分页、错误文本归一 |
| `ErrorText.swift` | `userFacingMessage(_:)`：`CatVodError` 优先，其它回落系统描述（首页/搜索共用） |
| `HomeView` | 工具栏左侧加放大镜入口（走 `adaptiveToolbar`，iOS 15 与 16+ 各自原生实现） |

要点：

- 提交用 `.onSubmit(of: .search)`，与系统搜索栏行为一致（回车触发）；分页按钮复用同一 `runSearch`。
- 切换站点会清空结果、页码与已提交关键词，避免把别的站点的结果显示成本站点的结果。
- 结果为空/加载中/未搜索分别有独立文案，不出现「空白列表无解释」。
- 详情跳转沿用 `VodDetailView(model:site:vodID:)`，播放设置仍由 `AppModel.playbackSettings` 注入。

## 验收

- CI：`CatVodUI (build only)` 编译通过（M02P3 新增的步骤）+ iOS/macOS 未签名构建通过。
- 人工（Mac 侧）：加载一个 CMS 源 → 首页右上角放大镜 → 输入片名 → 回车 → 出结果 → 点进详情 → 选集 → 播放。
