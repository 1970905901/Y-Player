- 状态：**规格已定，开工中** —— `PosterPicker`（取图策略）已落地并有测试；其余待做
- 时间：2026-10-09

- 依赖：M10i（下载入口在这套形态里也要有）

## 一、这是什么（先把话说清）

不是「详情页换个排版」。Emby 视图是一整套形态：**TMDB 元信息（海报 / 背景 / 简介）** + 站点给的
**文件级媒体**（带体积的真文件名），点进去的详情页就是参考视频里那个样子。

之前仓库里那个「Emby 视图」（设置 → 播放 → 播放页 → 显示视图）只是**排版风格**，没有元信息层。

## 二、设置项

切到 Emby 视图后才需要填：

1. **api key**（TMDB）
2. **api 代理地址**（TMDB 接口国内直连不到）
3. **图片代理地址**（图片域名同理）

❓ 待定：图片代理是**前缀拼接**还是要按 `{url}` 模板替换 —— 没定之前不写改写函数（猜错就是埋雷）。

## 三、取图策略：固定 / 随机 / 轮播

**顶部大图和选集卡片共用同一套** —— 视频里顶部那张会换、卡片每张也不同（f09/f10 可见各集图不一样）。

- 固定：永远第一张；
- 随机：**进页面定一次**，不是每步都变（每步都换 = 闪烁的图，像坏了）；
- 轮播：定时前进，到末尾回到开头。

已落地：`PosterPicker`（`CatVodUI/PosterPicker.swift`）+ `PosterPickerTests`。

## 四、详情页各区域（从视频逐帧读出）

| 区域 | 内容 |
|---|---|
| 顶部 | 全幅竖幅海报（取图策略）· 渐变压暗 · 大字标题 · 内容标（如「动漫」）· 线路胶囊 |
| 播放按钮 | **「继续播放」**（带**上次进度**，如 `· 01:51`）· 真实文件名 · 体积 |
| 图标行 | 🔍 搜索 → **多站点聚合搜索**海报墙 · ♡ 收藏 · ⋯ 更多（菜单三项） |
| 简介 | TMDB overview，约 3 行截断 |
| 选集区头 | 「线路名 ▾」· `\|◁ ▶\|` 上一集 / 下一集 · 更多 → **剧集列表抽屉** |
| 卡片 | 竖幅图（同一套取图策略）· 文件名 + 体积 · **当前集居中放大** |
| 中间态 | **骨架卡片**（灰色圆角占位）+ 按钮「⟳ 加载中」+ 图标置灰 |

### 「⋯」菜单三项（f02）

- **元信息刮削：开/关**（就在详情页上，不用回设置）
- **手动匹配元信息**（自动刮歪了能手动指定 TMDB 条目）
- **下载剧集**（与 M10i 同一件事，只是入口不同）

### 两个「更多」不是一个东西

- 图标行的 **⋯ 更多** → 上面的菜单；
- 选集区头的 **更多** → **剧集列表抽屉**（f07/f08/f12）：整屏文件列表、当前集高亮、
  右上排序 / 倒序、可滚动（叠加在页面上）。
