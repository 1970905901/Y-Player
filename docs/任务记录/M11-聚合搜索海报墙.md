# M11 片 5 聚合搜索海报墙

- 状态：**已实现**（本地静态自检过；真机由 YG 用 Mac 验证）
- 时间：2026-10-09
- 依据：`docs/任务记录/M11-Emby视图.md` 第五节（参考图 f03）
- 入口：详情页（Emby 视图）图标行的 🔍

## 一、规则（写死在这里，免得被「顺手统一」）

1. **搜哪些站点**（`AggregateSearchRules.searchableSites` / `targets`）：
   - 先只留下能搜的：`availability.isAvailable` + `searchAvailability.isUsable`；
   - 其中有站点标了 `indexs == 1`（上游语义：**索引站点，参与聚合搜索**）就**先**只搜这些；
   - **索引站点一条都没搜到，就补搜其余可搜站点**：空墙不等于「别的站点没有」，
     这面墙是给人挑入口用的，宁可多打一轮请求；
   - 一个 `indexs` 都没标就直接搜全部可搜站点（新配置常常没人标）。
2. **并发与失败**：目标站点一起跑（`TaskGroup`），**逐站 best-effort** —— 某站失败只跳过它、
   不拖累别的站点（与换源 `ChangeSourceService` 同一口径）。
3. **每站只取第一页**：这面墙是「挑一个入口」用的，不是浏览器；要翻页去搜索页。
4. **归位**（`AggregateSearchRules.sections`）：左栏**只列有命中的站点**，顺序照站点清单
   —— 并发谁先回来不该决定界面顺序；零命中与失败的站点都不占位。
5. **取图**走搜索页同一套 `PictureFiller`：墙上的海报与搜索页看到的应该是同一张。

## 二、界面（f03）

| 区域 | 内容 |
| --- | --- |
| 左栏（132pt） | 「全部 N」+ 各站点「名字 + 命中数」，选中的那行高亮 |
| 右栏 | 竖幅海报网格（2 列）：海报 + 片名 + 角标（复用 `DiscoverPosterCard`） |
| 点海报 | 进**那个站点**的详情页（`VodDetailView(model:site:vodID:)`），返回回到墙 |

- 本页**没有搜索框**：搜的就是详情页带过来的片名；换关键词回搜索页。
- 页面登记为沉浸页（`.immersiveTabBarPage()`）：详情 → 海报墙这一路都不出现底部 Tab 栏。
- 还在搜的时候左栏一条都不画：「全部 0」看着像搜完了没结果，加载态留给右栏说。

## 三、故意没做

- 不做翻页、不做「搜了几个站点 / 哪几个失败」的明细：失败与零命中同样不占位，左栏保持干净。
- 不做站点排序/固定：顺序就是配置里的站点顺序。
- 墙上不标「这一格来自哪个站点」：左栏选中即过滤，参考图也是这个形态（先按参考图来，有反馈再说）。

## 四、验证点（Mac）

1. 详情页图标行多出 🔍，点它是海报墙（不是空白页、也不是没反应）；
2. 左栏「全部 N」+ 各站点命中数；点某个站点，右栏只剩那一站；
3. 点海报进的是**那一站**的详情页（标题一致），返回回到海报墙；
4. 整个流程底部 Tab 栏都收着；
5. 配置里一个 `indexs=1` 都没有时，墙依然有内容（回落全部可搜站点）。
## 五、补记（2026-10-09 晚）

- 真机第一次打开只看到「各站点都没有搜到」——但「没有可搜站点 / 站点全失败 / 零命中」在界面上
  原本长得一模一样（`try?` 把失败吞了）。已改：`AggregateSearchOutcome` 带回
  `searchedCount` / `failures` / `didFallBackToAllSites`，空态按四种情况分开说，并加了「重试」。
- 同时补上「索引站点零命中 → 搜其余可搜站点」这条回落：否则索引站点一挂，墙就永远是空的。
