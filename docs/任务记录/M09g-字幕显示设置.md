# M09g 字幕显示设置（开关 / 字号 / 位置 / 背景）

- 状态：设置页与持久化落地，9 条单测 + 偏好往返测试；**屏上观感待真机确认**
- 时间：2026-10-09
- 依赖：M09f（字幕上屏）、M08i（弹幕显示设置 —— 同一套做法）、M08f（偏好存储走注入的 `defaults`）

## 一、与 M08i 同一套做法

M09f 把字幕画上去了，但那四项是写死的默认值。这轮按 M08i（弹幕显示设置）的形状补上设置页 ——
结构一模一样：**可持久化的配置类型 + 设置页 + 上屏桥（`style`）**，只是内容不同。

| 设置 | 类型 | 取值 | 落到哪 |
| --- | --- | --- | --- |
| 显示字幕 | `Bool` | 开（默认）/ 关 | 覆盖层挂不挂 —— **不是**显示参数 |
| 字号 | `Double` | 0.5×…1.6×（默认 1×） | `SubtitleDisplayStyle.fontScale` |
| 位置 | `SubtitlePosition` | 低 / 中 / 高（默认低） | `bottomInset` 的**倍率** |
| 背景 | `SubtitleBackground` | 无 / 半透明 / 深色（默认半透明） | `backgroundOpacity` |

## 二、两处刻意的取法

1. **位置取「底边距的倍率」而不是「画面高度的百分比」**：「低」这一档因此与原行为**逐点相等** ——
   默认档必须等于上一版，才谈得上「不碰设置就什么都不变」。其余档（1 / 2.5 / 5 倍）再往外推；
2. **字号倍率与「按画面高度缩放」相乘、互不干扰**：后者是为了不同尺寸设备上观感一致的**必要修正**，
   前者是用户偏好，两者默认值都不影响对方（单测：参考高度下 1.5× 正好是 30pt）。

## 三、开关只管「画不画」

关掉之后覆盖层直接不挂上去（`isVisible` 是渲染前的门），所以是**立刻消失**，不用重进页面 ——
与弹幕开关「关掉就清屏」同一个语义。它**不进显示参数**（单测钉住：开与关解出来的
`SubtitleDisplayStyle` 完全相等）。

字幕要不要**去取**仍然取决于站点给没给 `subs`，与这个开关无关 —— 两件事分开。

## 四、预览是一块缩小的小画面

字号 / 位置 / 背景三项光看档位文字判断不了，所以预览把字幕放进一个 110pt 高的小黑块里
（字号与底边距都按**同一份** `resolved(height:)` 算，只把高度换掉）。预览什么样，屏上就什么样。

## 五、持久化

与 `DanmakuDisplayConfig` 同一套：`显示|字号|位置|背景` 竖线拼接、`String(Double)`（locale 无关、
往返精确）、格式不对**整体**回落默认、越界与 `NaN` 在 `init` 与 `decode` 两处都夹、
写入走注入的 `defaults`（M08f），并已加进 `AppModelIntegrationTests.preferencesRoundTrip`。

## 六、没做（留口）

- **字幕延迟（±秒）**：外挂字幕与片子对不齐是常事（站点给的 `.srt` 常差半秒到几秒）。
  要加它是「一个 `Double` + 一次夹取 + 查询时把时刻挪一下」——接口上早留好了
  （`SubtitleTimeline.cues(at:)` 只认一个时刻）。这轮没做是因为你没提，要做说一声；
- 每集 / 每站点各自的字幕偏好（现在是一份全局设置）；
- 手动选字幕轨（站点给多条时，`SubtitleService.pick` 直接挑第一条可用）。
