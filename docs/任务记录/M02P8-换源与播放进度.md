# M02P8 换源与播放进度（M2 收尾）

- 状态：已随 CI 全绿（2026-10-08 统一回填：本行原写「待 CI 验证」；播放进度的落库实现由 M08a/M08b 补齐）
- 时间：2026-10-07
- 范围：M2 剩余两项 —— ① 详情页「换源」；② 播放进度记忆（接口预留 + 可用实现 + UI 接线）

## 一、换源

### 核心（`CatVodSource/Client/ChangeSourceService.swift`）

```swift
let candidates = await model.makeChangeSourceService()
    .candidates(title: vodName, sites: model.sites, currentSiteKey: site.key)
```

规则（刻意写得可预测）：

| 规则 | 说明 |
| --- | --- |
| 跳过永久禁用 | `changeable == 0`（`FeatureAvailability.disabled`）不打请求 |
| 跳过不可用站点 | 如 `csp_*.jar`（本平台无 JVM）——复用 `Site.availability` |
| 限量 | `maxSites`（默认 8）：换源不该把整份配置全打一遍 |
| **best-effort** | 单站搜索失败只跳过，不影响其它站点（整体不抛错） |
| 排序 | 匹配度降序 → 同分时当前站点优先 → 其余保持配置顺序 |

片名匹配度 `matchScore`（**启发式**，不声称与上游一致）：归一化（去空白/中英标点、小写）后
完全相同 `1.0` → 前缀 `0.85` → 包含 `0.7` → 字符集合重合 ≥60% 记 `0.5` → 否则 `0`（UI 不展示）。

### 界面（`CatVodUI/ChangeSourceView.swift`）

详情页工具栏「换源」→ sheet 列出候选（站点名 / 匹配度 / 备注 / 「当前站点」标记）→ 选择后就地替换
`site` + `vodID` 并**清空** `detail`/`lines`/线路选择后重新加载 —— 不清空会出现「站点已换、选集还是旧的」串数据。

## 二、播放进度

### 接口预留（`CatVodStore/PlaybackProgress.swift`）

- `PlaybackProgress`：`key`（站点+vodID）、`position`、`duration`、`isFinished`、`episodeIndex`、`updatedAt`；
  - `resumePosition()`：**已看完**或**进度 < 5 秒**一律从头播（避免「点进去停在片头几秒」）；
  - `fraction` / `isEffectivelyFinished`（≥95% 视为看完）。
- `PlaybackProgressStore` 协议（`Sendable` + 四个 `async` 方法）+ `InMemoryPlaybackProgressStore`（M2 可用）。
- **M8 只需实现同一协议**（GRDB）并替换 `AppModel.progressStore` 的构造，UI 不改。

### 接线

| 位置 | 行为 |
| --- | --- |
| `PlaybackView.start()` | 有记录则用 `resumePosition()` 覆盖 `resource.startPosition`，并提示「已从上次位置续播（12:34）」 |
| 播放中 | `timeChanged` 事件驱动落库，**节流 5 秒**一次（不必每秒写） |
| 暂停 / 播放结束 / 离开页面 | 强制落库一次；`ended` 额外标记 `isFinished` |
| 「从头播放」按钮 | 清进度 + seek 到 0 |
| 详情页 | 头部显示「上次看到 · 第 N 集 · 12:34」，选集行标「上次看到」 |

## 三、明确未做（诚实记录）

1. **跨线路/跨站的集身份对齐**：`episodeIndex` 只是「当前线路内下标」，换线路后标记可能指错集；
   正确做法是用集名或 url 归一化匹配，与 M8 的落库一起做。
2. **进度落库**：M2 是内存实现（**杀进程即丢**），GRDB 在 M8。
3. **进度同步**：上游的观影记录同步（Nostr/TMDB 等）属后置里程碑。
4. **换源不做「线路级」对齐**：只把「站点+条目」换掉，不尝试把集号映射到新站点的对应集（同上，留给 M8 的集身份对齐）。

## 四、验收

- 单测：`ChangeSourceMatchTests`（四档匹配度）、`ChangeSourceServiceTests`（禁用/不可用站点跳过、单站失败兜底、排序、maxSites、空片名不打请求）、`PlaybackProgressStoreTests`（续播规则、比例、增删查、按站点隔离）。
- CI：`CatVodSource tests` / `CatVodStore tests` / `CatVodUI (build only)` + 双端构建。
- 人工：详情页点「换源」应列出其它站点同名条目；选一个后详情与选集整体刷新；播放 20 秒后退出再进应续播并显示「上次看到」。

## 五、回滚

两处都是新增文件 + 局部接线：删除 `ChangeSourceService.swift` / `ChangeSourceView.swift` /
`PlaybackProgress.swift` 并把 `PlaybackView`、`VodDetailView` 的参数去掉即可；`AppModel` 的
`progressStore` 与 `makeChangeSourceService()` 是独立属性，不牵动其它功能。
