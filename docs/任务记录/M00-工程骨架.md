# M00 工程骨架

- 状态：已完成
- 时间：2026-10-07
- 范围：仓库初始化、包结构、工程规范、CI、文档骨架

## 目标

在不依赖任何 Apple 工具链的前提下，把可编译、可单测、可 CI 的工程骨架落到仓库，
让 M1（协议核心）与 M1.5（js2p 宿主）能立刻开始，并且**首次 CI 必定为绿**。

## 决策与依据

| 决策 | 依据 |
| --- | --- |
| SwiftPM 六包 + XcodeGen 双 target | 业务分层清晰，`CatVodCore` 保持纯 Foundation，可在任意平台单测 |
| 包清单在 M0/M1 只含本地依赖 | MPVKit（M3）、GRDB（M2）、FlyingFox（M6）分阶段引入，避免首次 CI 因解析外部依赖失败 |
| iOS 15.0 / macOS 13.0（原生，不用 Catalyst） | MPVKit 下限为 iOS 15，与之一致；macOS 用原生 target 以获得更好的桌面体验 |
| Swift 6 语言模式分模块启用 | Core/Net/Source/Store 用 v6；Player/UI 与 C API 交互密集，先用 v5，接口稳定后迁移 |
| 宽松解码用手写 `init(from:)` + 非抛错辅助方法 | 合成解码对「键缺失」的降级行为依赖编译器实现细节，风险不可控 |
| CI 基线 `macos-15` + Xcode 16.4，lint 非阻断 | `macos-14`（唯一含 Xcode 15 的镜像）将于 2026-11-02 停止支持；先保证构建与单测绿，再收紧 lint |
| 发布产物未签名 | 使用者自行侧载/重签，CI 不需要任何签名 secrets |

## 产出清单

- 根目录：`.gitignore`、`.editorconfig`、`.swiftlint.yml`、`.swiftformat`、`project.yml`、`README.md`、`LICENSE`(GPL-3.0)
- `Packages/`：`CatVodCore`、`CatVodNet`、`CatVodSource`、`CatVodPlayer`、`CatVodStore`、`CatVodUI`（含各自测试 target）
- `Apps/`：`YPlayer-iOS`、`YPlayer-macOS`（入口 + Info.plist 由 XcodeGen 生成）
- `.github/workflows/build.yml`：lint（非阻断）→ 单测 → 双端构建 → tag 发布（未签名 ipa/zip）
- `ThirdParty/mpvkit.lock.json`：MPVKit 版本、许可证与已核对的 checksum
- `docs/`：架构、协议兼容矩阵、js2p 宿主契约、构建与分发、任务记录

## 验收

1. `swift test --package-path Packages/CatVodCore` 等命令在 macOS 上通过。
2. `xcodegen generate` 能生成工程；`xcodebuild build`（iOS 模拟器与 macOS，未签名）通过。
3. CI 在 push 后全绿；打 tag 后产出未签名 ipa 与 mac zip。

## 回滚

本任务只新增文件，不涉及既有代码。回滚方式：删除 `Packages/`、`Apps/`、`docs/`、`project.yml`、`.
github/workflows/build.yml` 与其余新增根文件即可。
