# M04P21 软解 10bit（P010 → x420）

- 状态：**已实现**（本地静态闸门全绿 + 新单测；Mac 编译 / 测试 / 上机待 YG）
- 时间：2026-10-10
- 触发：M04P18 当时把「10bit 软解（P010 → x420）」列进故意没做（先把 8bit 那条路的成本降下来）；
  现在两条前置都齐了 —— 色彩附件接通（M04P20）、模拟器上只有软解这条路能走 ——
  10bit 片源（HEVC Main10 是 4K 站的常态）再被压成 8bit 就是白丢一档信息。

## 一、做法

1. **源是 10bit 就 10bit 出**：`yuv420p10le` / `p010le` → sws 目标 `P010LE`；其余源照旧 `NV12`。
   映射写成 `softwareTargetFormat(_:)`（纯函数：目标由源推出，sws 的缓存键还是「源格式 + 尺寸」）。
2. **CoreVideo 侧就是 x420**：`P010LE` 与 `kCVPixelFormatType_420YpCbCr10BiPlanarVideoRange`
   是同一套排布（10bit 双平面、高位对齐、little-endian）—— sws 直出，不用自己搬位。
3. **平面拷贝照旧**：`copyPlane` 本来就是字节级拷贝（行宽取两边小的），10bit 两边排布一致，一行没改。
4. **色彩标签照挂**：M04P20 那套「按源挂 CV 标签」与位深无关，PQ / HLG 自然跟着 x420 出去；
   播放信息「输出」那行随之写 `x420`。

## 二、口径与取舍

- **只做 4:2:0 的 10bit**（`yuv420p10le` / `p010le`）—— HEVC Main10 的常态输出；
  4:2:2 / 4:4:4 的 10bit 仍不在白名单里（与 8bit 一致：认不出就丢帧记账，不硬撑）。
- **不做 tone mapping / 色域转换**：值原样带出去，标签告诉显示层怎么解释（HDR 真不真看显示侧）。
- 8bit 源照旧 `420v`，一个字没变。

## 三、故意没做

- P010 → BGRA 之类反回来的转换（显示层吃 YUV，不做来回倒腾）；
- 10bit 的 4:2:2 / 4:4:4；
- 软解 HDR 的显示侧配置（EDR）：那是 M04P2 真机验收的事，不在解码这条线上。

## 四、验证点（Mac）

1. `swift test --package-path Packages/CatVodPlayer`：新一条 ——
   「软解 10bit：10bit 源（y4m 原始帧）→ x420 输出」（夹具现场写 10bit y4m，断言像素格式 / 平面数 / 尺寸 / 时间戳）；
2. 全包测试 + App 编译照旧；
3. **上机**（模拟器，软件解码）：播一个 HEVC Main10 的片子 → 播放信息「输出」应写 **x420**
   （8bit 片源仍是 `420v`）；画面 / 声音应与 8bit 版无感差 —— 这条是给 M04P2 的 HDR 验收铺路。

## 五、教训（写给下一次）

- **想让 AVAssetWriter 编 10bit HEVC，这条路在这台 SDK 上是死的**：不给 profile 它默认编 8bit Main
  （x420 源也会被压成 8bit —— 首轮 Mac 测试抓到，输出还是 `420v`）；显式给
  `AVVideoProfileLevelKey: kVTProfileLevel_HEVC_Main10_AutoLevel` 又直接被判非法 key 抛
  `NSException`（`Output settings dictionary contains one or more invalid keys: ProfileLevel`）。
  最后改用 **y4m（YUV4MPEG2）原始帧文件**当夹具：FFmpeg 原生裸帧容器，10bit 数据原样进
  rawvideo 解码器，走的还是同一条「源格式 → sws → x420」—— 要测的东西一样，还不用求编码器。
  教训：**夹具要测的是「我们这条链路」，不是「系统能不能编 10bit」** —— 前者用最矮的输入就够，后者不是这单测的职责；
- y4m 的 10bit 帧就是「`FRAME\n` + 小端 16bit 样本、`C420p10` 标记」（`appendSamples` 那几行），
  以后要造别的位深（9/12/16）照这个格式加一行就行；
- 「P010 ↔ x420 同一套排布」是敢用字节级拷贝的依据：两边都是 16bit 字里放 10bit 值、MSB 对齐；
  哪天要接 P010BE（大端），这条不成立，得显式换序。
