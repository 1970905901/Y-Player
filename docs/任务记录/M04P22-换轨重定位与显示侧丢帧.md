# M04P22 换轨重定位 + 显示侧丢帧（播放器零碎之一）

- 状态：**已实现**（本地四闸门全绿 + 新单测；Mac 编译 / 测试 / 上机待 YG）
- 时间：2026-10-10
- 触发：M04P16 / M04P15 两处留口 ——「换轨后的重定位（新轨与画面重新对齐）」与
  「显示侧丢帧计数（`AVSampleBufferDisplayLayer` 没有这种计数可读）」。
  同批的「逐帧步进 / 音频增益」是另一片（M04P23 起做）。
- 依据（上游/参照）：ExoPlayer 换轨（`setTrackSelection` 之后重新定位到当前位置）；
  our own M04P12 seek 机制（跳关键帧 + 两侧 flush + 时间轴重定位）—— 重定位直接复用它。

## 一、做了什么

### 1）换音轨后重定位（自研 FFmpeg）
- 旧口径（M04P16 的 v1）：换完**不回头**，新轨从「当前读包位置」往后接 —— 而读包位置在显示位置
  **前面**（解码线程总是先读一段缓冲着），于是换完先静一下、再从中途接上，听感是
  「换轨之后声音要等半秒才对得上口型」；
- 新口径：换完**按当前显示位置重定位** —— 复用 `performSeek(to: videoRenderer.currentSeconds)`：
  输入跳关键帧 + 两侧解码器 flush + 时间轴重定位（`reset(to:playing:rate:)`）。
  画面有一次很短的补帧（从目标前一个关键帧接上），换来的是新轨与画面重新对齐。

### 2）顺手修的老账：暂停着拖进度条会被「按回播放」
- 病根：`startedPlaying` 一个旗标兼了**两个身份** —— 「看门狗的门」（出过帧才谈饥饿）与
  「这一路是不是开播过」。`performSeek` 会把前者压回去（seek 后重新等第一帧），
  写进 `enqueue` 的那段「第一帧 ⇒ `playing = true` + `videoRenderer.play()`」于是对 seek 后的
  第一帧也成立：**暂停中 seek 会被自动复播**（换轨重定位走同一条路，同一把刀）。
- 修法：拆成两个旗标 —— `startedPlaying`（门，seek 后压回）与 `hasStartedEver`（只有第一次
  真开播才允许把 `playing` 打开）。喂帧从此**不再改播放状态**（M04P17 那条「同一个状态不要
  有两条路径」的老规矩）。

### 3）显示侧丢帧有了读法（自研 FFmpeg）
- `AVSampleBufferDisplayLayer` 自己**不报丢帧**（M04P15 记过），所以这是**我们的口径**：
  **帧没能进显示层（转样本失败）的次数** = 会话在 `enqueue` 拿到 `false` 时记一笔；
- 迟到帧**不算**丢帧：显示层会把它们立刻补显（表现是短暂追帧，不是丢帧）——
  写清楚免得下一个人把它也算进来；
- `stats()` 现在**两侧都报**（数字 0 也写）：`显示 X · 解码 Y` / `无丢帧` ——
  「无丢帧」只有在**真的读到** 0 时才是真话（M04P15 定的口径）。

## 二、口径与取舍

- 重定位复用整段 seek，而不是「只把新轨拽回当前时刻」：输入层只有一个读包位置，
  单独拽音轨要么再开一个 demuxer、要么手写「丢视频包到目标」那一套 —— 复用 seek 的代价
  只有一次很短的补帧，收益是两侧**同一时刻**重新对齐（上游也是重新定位整套）；
- 显示侧丢帧**不偷懒写 0**：只有自己数得出来的那种才报（转样本失败）；层 failed / 中断恢复
  丢掉的那些**不算**（那是恢复动作，不是丢帧）。

## 三、故意没做

- 逐帧步进 / 音频增益（同批的另一片，M04P23 起做）；
- 「迟到帧」计数：见上，它不该算丢帧；
- 换轨时的**音频淡入淡出**：上游没有，本批不做（有一小段静音是重定位的必然产物）。

## 四、验证点（Mac）

1. `swift test --package-path Packages/CatVodPlayer`：新 2 条（显示侧丢帧报得出来；
   暂停时 seek 不许复播）+ 换音轨那条补了「按当前显示位置重定位」的断言；
2. 全包测试 + App 编译照旧；
3. **上机**（自研 FFmpeg 内核，多音轨的片）：
   - 播放中换一条音轨 → 声音**当场**接着走（不再静默半秒 / 不对口型）；
   - 暂停 → 拖进度条松手 → 仍然是暂停（以前会被按回播放）；
   - 播放信息里「丢帧」那行现在会写「显示 X · 解码 Y」或「无丢帧」。

## 五、教训

- **一个旗标别兼两个身份**：`startedPlaying` 兼了「看门狗的门」与「开播过没有」，
  于是 seek 后第一帧把暂停按回去 —— 拆开之后两条语义各自可读（M04P17 那条老规矩的又一次应验）；
- 留口的「不做」要写清**为什么**：「读包位置在前、显示位置在后」这句话让「不做重定位」的
  后果（静一下再中途接上）一眼可查，而不是一句「先不做」。
