# M03P5 音轨与字幕轨选择（MPV）

- 状态：**已实现**（本地静态自检过；真机由 YG 用 Mac 验证）
- 时间：2026-10-09
- 起因：A 计划「把 MPV 补成日常可用」第一块 —— 4K 网盘片源常见多音轨 / 内封字幕，
  此前 `PlayerEvent.tracksChanged` 有事件、**没有任何内核上报**（M03P3 的「已知未做」第 4 条）。
- 依赖：M03P3（MpvEngine 状态机）、M03P4（渲染路径）

## 一、怎么读轨道列表（选型理由）

| 方案 | 结论 |
| --- | --- |
| `mpv_observe_property("track-list", MPV_FORMAT_NODE)` | ❌ 要接一整套 node 解析（mpv 的 mpv_node / mpv_node_list 手写遍历），为几行下拉框不划算 |
| `MPV_EVENT_TRACKS_CHANGED` | ❌ 上游已标为弃用，且我们的事件 seam 只认几种事件 |
| **`mpv_get_property_string("track-list")` 读一次** | ✅ mpv 会把结构化属性转成 JSON 字符串；`file-loaded` 后读一次就拿到全量轨道 |

所以：seam 加 `propertyString(_:)`（`MpvSession`），`LibmpvSession` 用 `mpv_get_property_string` + `mpv_free`；
**解析在纯映射层**（`MpvEventMapping.trackIDs(fromTrackListJSON:)`，可单测）：
只认 `type` 为 `video` / `audio` / `sub` 的条目，**封面图轨道**（`albumart == true` 的 video）排除；
解析失败返回 `nil`（调用方什么都不发 —— 别发空列表把界面上的选择清空）。

时机：`MpvEngine` 收到 `file-loaded` 后读一次并 `emit(.tracksChanged(video:audio:subtitle:))`。
换片必然再来一次 `file-loaded`，够用；播放中动态增删轨道不追（见「故意没做」）。

## 二、界面（播放页「轨道」区）

- `PlaybackView` 的 List 里新增「轨道」区：音轨用 Picker（自动 + 各音轨 id），
  字幕多一项「关闭」；改选立刻 `engine.selectTrack(_:for:)` 下发；
- **只有内核报了轨道才出现**：`AVPlayerEngine` 目前不上报轨迹，系统内核下这块不显示 ——
  不做「点不动的假菜单」（这条沿用了仓库对不可用能力的一贯口径）；
- 轨道变化（换片）时界面选择回到「自动」，由内核挑默认轨。

## 三、故意没做

- **不给轨道显示语言 / 标题**：`PlayerEvent.tracksChanged` 的载荷是 id 数组（事件是 M2 定的公共形状，
  AV 内核以后也要用）。要带 `lang` / `title` 得改事件载荷 —— 等真的嫌「音轨 1/2」难认时再一起改；
- **不给系统内核（AVPlayerEngine）接轨迹**：那是另一块（AVMediaSelectionGroup），单独一片；
- **不观察播放中的轨道增删**（HLS 变体切换等）：需要 observe node，等有实际案例再说；
- 没做字幕样式（字体/描边）在 MPV 下的透传：我们自绘字幕层已经覆盖这件事。

## 四、验证点（Mac）

1. 设置 → 播放 → 内置核选 **MPV**；找一部**多音轨或带内封字幕**的片；
2. 播放页出现「轨道」区：音轨能切（声音立刻换语言）、字幕能切/关；
3. 换一集：轨道区跟着换源更新，选择回到「自动」；
4. 切回系统播放器：**不出现**「轨道」区（不上报就不显示）。
