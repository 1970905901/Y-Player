## 设计要点

1. **传输层只负责发请求**：DoH / hosts 覆盖 / SOCKS5 代理在 M6 通过自定义 `URLProtocol` 与本地代理服务补上；此处先把配置驱动的规则（header、ads）做实。
2. **解析失败与空数据区分**：空响应体按协议给空结果（`SpiderResult.empty`），非法 XML/JSON 抛 `CatVodError.decoding`，不把 HTML 错误页当结果。
3. **XML 与 JSON 共用同一输出模型**：`type=0` 解析结果与 JSON 结果都落到 `SpiderResult`，UI 与播放层不感知差异。
