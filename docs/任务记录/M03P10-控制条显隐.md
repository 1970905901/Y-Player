# M03P10 自绘内核的控制条：单击显隐 + 播放中自动收起

- 状态：**已实现**（控制条显隐状态 + 单击/双击优先级 + 自动收起；新单测）
- 时间：2026-10-10
- 触发：M03P6 挂的留口第 1 条 —— 「单击显隐控制条：单/双击判定要靠手势竞技场，做不好会出现
  「双击时控制条先闪一下」」。自绘内核（MPV / 自研 FFmpeg）的最小控制条此前**一直贴着画面底部**，
  看片时既挡画面又不像播放器。

## 一、单击与双击怎么共存（M03P6 担心的那一处）

用 `exclusively(before:)` 组合，而不是叠两个 `.onTapGesture`：

```swift
TapGesture(count: 2)
    .onEnded { _ in Task { await togglePlayback() } }
    .exclusively(before: TapGesture(count: 1).onEnded { _ in toggleControlsVisibility() })
```

双击**先决**：单击只在「没有第二下」之后才触发 —— 所以双击播放/暂停时控制条不会先闪一下；
代价是单击要等一个双击判定窗口（与系统播放器一致的手感）。拖动手势照旧挂在同一层（`minimumDistance: 24`，
与点击不冲突）。

## 二、什么时候收起

`controlsShouldAutoHide(isVisible:state:)`（**纯函数、有单测**）：只有「看得见 + 正在播」才排
「4 秒后自动收起」；暂停 / 缓冲 / 结束 / 失败都**亮着**（那时人要看它）。三条接线：

- 引擎 `stateChanged`：进 `.playing` 就重排计时，其它状态直接 `showControls()`（取消计时 + 亮出）；
- 单击画面 / 拖动进度条松手：重排计时（交互过就从 0 算）；
- 离开页面（`onDisappear`）：取消计时（不留一个什么都不做的任务）。

显隐带 0.2s 淡入淡出（`transition(.opacity)` + `animation(_:value:)`）。

## 三、只管自绘内核

系统内核（`VideoPlayer`）自带一整套控件与手势，我们**不叠**（M02P15 起就是这条口径）——
这一段只在 `mpvSurface != nil || ffmpegSurface != nil` 时存在。

## 四、测试

`PlaybackControlsTests` 4 条：正在播且可见 → 收起；暂停/缓冲/结束/失败/未开始 → 不收起；
已收起 → 不再排；等待时长 = 4 秒。
