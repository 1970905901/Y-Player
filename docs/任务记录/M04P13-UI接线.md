# M04P13 UI 接线（自研内核进播放页 + 可用性翻牌）

- 状态：**已实现**（本地静态闸门全绿；Mac 编译 / 测试 / 上机出画面待 YG）
- 时间：2026-10-10
- 触发：M04P12 seek 就位 —— M04 线的功能件全齐，就差最后一截：界面还没用上它（`.ffmpeg` 不可选）。

## 一、做法

1. **画面层宿主抽公共**：`LayerHostView`（CALayer 宿主，iOS/macOS 两分支）从 `MpvVideoView` 里提出来，
   `MpvVideoView` 与新的 `FFmpegVideoView`（挂 `AVSampleBufferDisplayLayer`）共用同一套「挂层 + 跟随尺寸 +
   关隐式动画」；层的生命周期仍归各自的 Surface（引擎持有），视图重建不换层。
2. **播放页接线**：`PlaybackView.start()` 选 `.ffmpeg` 时先建 `FFmpegVideoSurface`（画面层要在建引擎**之前**
   交出去，同 MPV 的 `wid`），经 `PlayerCoordinator.makeEngine(..., ffmpegSurface:)` 建引擎；画面区加
   `FFmpegVideoView` 分支。控制条与手势从「MPV 专用」改成自绘内核通用（`playerControls` / `playerGesture` /
   `interactiveLayer`），两个自绘内核共用同一条。
3. **可用性翻牌**：`FFmpegAvailability.isEngineImplemented` → true；`PlayerEngineKind.ffmpeg.isAvailable`
   改成 `isEngineImplemented && isComplete`（引擎实装 + Libav 六件套真的在，与 `.mpv` 的「两个都真」同形）。
4. **创建路径**：`makeEngine` 加 `ffmpegSurface` 参数，**没给画面层照样返回 nil** ——
   同 MPV 的纪律：宁可说「不可用」，也不给一个没有画面的播放器。不可用文案随之从「引擎尚未实装」改成
   「建引擎时没有给它画面层」。
5. **播放信息自动生效**：界面那块是用「引擎认不认 `PlaybackStatsProviding`」判的（M04P1 留的口子），
   自研内核认这个协议，所以这次**一行都没改**就上了屏（打开时读到的事实：分辨率 / 编码 / 容器 / 硬解）。
6. **文案改口径**（设置页）：三个内核都不再有「（未接入）」；自研内核写明「当前只有硬解 + 默认音轨，
   软解 / 音轨切换在后面补」；解码方式那条提示补一句「自研 FFmpeg 目前只支持硬解」。
   兼容矩阵补一行「自研 FFmpeg 内核」，播放那行的「待 M4」改成已可播。

## 二、口径与已知取舍

- `PlaybackView` 的类型体到约 420 行（SwiftLint warning 300 / error 450）——**再往里加东西之前先拆 extension**。
- 自研内核的 `stats()` 是**打开时的事实**（不是 mpv 那种逐帧快照），注释里如实写着。
- 轨道选择区对自研内核**不显示**（会话还没有轨道可报；不摆一个选了没用的控件）。
- 软解 + 自研内核会在会话 `open` 时被明确拒绝（提示换硬解），不静默改用硬解。

## 三、故意没做

- 软解回退、音轨切换、字幕（libass）上屏、逐帧步进 / 音频增益这些内核专属控制；
- **M04P2 现场验收**（色彩 / 输出两行）：要 HDR 片源看真效果，等这次能出画面后单独做。

## 四、验证点（Mac）

1. `swift test --package-path Packages/CatVodPlayer`：
   - 「FFmpeg 内核依赖探针」改断言**可用**（引擎已实装 + 依赖全齐），不可用原因文案分支跟着改；
   - 「MPV 内核可用性」里 `.ffmpeg` 那条从 false 翻 true（三个内核都不再「未接入」）；
   - 「播放设置」两条重写：不降级那条改成三个内核都原样 `.ready`；没画面层建不出自绘内核、给了就建得出来。
2. 全包测试 + App 编译照旧；
3. **上机（重头戏）**：设置 → 播放设置 → 内核选「自研 FFmpeg」→ 播一集 → **第一次出画面出声**。
   盯：首帧、暂停 / 继续、拖进度 seek、纵拖音量、播完自动结束 / 自动连播。
   （模拟器没有 HDR，「色彩 / 输出」两行留到 M04P2。）
