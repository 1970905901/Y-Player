# M03P21 播放页锁屏 / 防误触（对齐上游 `setLock`）

- 状态：**已实现**（本地静态闸门全绿 + 新单测；Mac 编译 / 测试 / 上机待 YG）
- 时间：2026-10-10
- 触发：自绘内核的手势现在有 7 条（单击 / 双击 / 横拖 / 左半屏纵拖 / 右半屏纵拖 / 长按加速 / 捏合），
  拿着手机看容易误触 —— 上游播放页有一个「锁」（`control.right.lock`，`CustomKeyDown.setLock`）。
- 依据：`VideoActivity.onLock`（`setLock(!isLock()` + `mKeyDown.setLock` + `showControl`）、
  `CustomKeyDown` 里每条手势回调的早退、`onUserLeaveHint` 里的自动解锁、`control.right.lock` 图标切换。

## 一、上游口径 → 本项目

| 上游 | 这里 |
| --- | --- |
| 控制条右侧一个锁按钮，点一下切换 | 自绘控制条右端一个锁按钮（`lock.open` / `lock.fill`），点一下切换并 `showControls()` |
| 锁上后：**控制条只剩锁按钮**（center/bottom/back/top/danmaku 全 GONE，control root 仍可见） | 锁上后控制条的常规内容整块藏起来，只留锁按钮（`playbackControls` / `lockButton`） |
| 锁上后手势全停（`mKeyDown.setLock(true)` → 每条回调早退） | 双击 / 拖动 / 长按加速 / 捏合全停；**只留单击**（`LockedGesturePolicy`，纯函数有单测） |
| `onSingleTap` 不看 lock → 锁着也能把控制条叫出来 | 同：锁上时那条只剩解锁按钮，单击是把它叫回来的唯一办法 |
| `onUserLeaveHint`：离开 App 自动解锁 | `scenePhase` 非 active 时自动解锁（回来看见的是能点的画面） |
| 锁状态随 Activity（不落盘） | 页面内 `@State`（退出播放页即失效） |

## 二、口径

- **锁的是「画面 + 控制条」**：信息区（下面的列表）不锁 —— 那是滚动区，不是误触重灾区；
  上游是全屏播放页，没有这一段可对应（差异记在这里）；
- **锁与「自动收起」共存**：控制条（此时只有锁按钮）播放中照样会自动收起，单击叫回来；
- **系统内核不锁**：`VideoPlayer` 自带控件，锁了它反而自相矛盾（与「手势只挂自绘内核」同一条口径）。

## 三、故意没做

- **锁定时的方向锁 / 旋转控制**（上游 `PlaybackOrientation.getLockOrientation`）：我们没有旋转锁；
- **锁上后隐藏信息区**：见上；
- **落盘**：退出播放页即失效（与上游一致）。

## 四、验证点（Mac）

1. 自绘内核播放中 → 控制条右端出现锁按钮 → 点一下：控制条只剩锁按钮，画面上的双击 / 拖动 /
   长按 / 捏合**全都不响应**；
2. 单击画面 → 控制条（只剩锁按钮）显隐正常 → 点解锁 → 手势全部回来；
3. 锁着的时候按 Home 退到后台再回来 → **自动解锁**（画面能点）；
4. 系统内核（系统播放器）**没有**这个锁按钮。
