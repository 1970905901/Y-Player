# M07d-3 播放页换台（上一台 / 下一台）

- 状态：**CI 全绿**（`d5d2cab`；逐条复盘见 `M07d2-直播源切换.md` 第六节）
- 时间：2026-10-08
- 范围：直播播放页的**换台**：当前分组内环形切换，跳过没有地址的频道，换台写回「上次观看」
- 前置：M07c-3（线路切换与 keep）、M07c-5（收藏分组）
- 上游依据：`Tools/out/upstream/parts/…LiveActivity.java` 的 `mBinding.control.next/prev` →
  `mLive.nextChannel()` / `mLive.prevChannel()`（`mLive` 那个类的源码不在本地取自的清单里），
  以及手势分支 `onFlingUp` / `onFlingDown` + `LiveSetting.isInvert()`

## 一、为什么补这个

直播里「换台」是每天要按几十次的动作，而在此之前只能**退回列表再点另一个频道** —— 播放页没有任何
切换入口。这是这条线上最缺的高频操作（比 M07d-1/-2 那两个设置项日常得多）。

## 二、落地了什么

| 件 | 说明 |
| --- | --- |
| `CatVodCore/Vod/Live/LiveChannelNavigation.swift` | 纯逻辑：`neighbor(of:step:in:)` —— 组内环形、跳过没有地址的频道、可播不足两个返回 `nil` |
| `CatVodUI/LiveView.swift` 的播放页 | 工具栏左上角「上一台 / 下一台」（没有可换的自动置灰）；换台 = 换频道 + 线路重置到第 0 条 + 写回 keep + 拉新频道节目单；播放页的重建键从「线路」改成「频道 + 线路」 |
| 单测 | `CatVodCoreTests/LiveChannelNavigationTests`（4 例：环形与跳过、大跨度与绕圈、频道不在清单里、没有可换的） |

## 三、对齐与差异

| 上游 | 本仓库 | 差异 |
| --- | --- | --- |
| `control.next` / `control.prev` → `mLive.nextChannel()` / `prevChannel()` | 工具栏两个按钮 + `LiveChannelNavigation.neighbor` | 上游那对方法的**定义**没取到（在 `player/` 那个类里），所以三条语义（组内 / 环形 / 跳过不可播）是按通行做法定的，不是照抄 —— 已写进测试与注释 |
| 竖向滑动换台（`onFlingUp` / `onFlingDown`）+ `LiveSetting.isInvert()` 反转方向 | ~~不做手势~~ → **M07d10 已做** | 当时给的理由（「播放页是系统 `AVKit.VideoPlayer`，手势面归它」）在自绘内核（M03P6 / M03P12）上来之后**过期了**：手势层现在是我们的，M03P23 的甩判定直接复用 —— 见 `M07d10-直播手势换台.md` |
| `Channel.setIndex(...)`：每条线路各自记下标（换台/换回来都记得） | 换台**线路重置到第 0 条** | 每条线路的可用性各频道不同，沿用旧下标可能撞上「这个频道没有第 N 条」→ `playbackURL(index:)` 给空地址 → 直接播不了。重置是可预期的行为；要第 N 条就再点一次线路菜单 |
| 换台会滚动到列表里对应位置 / 更新 EPG 面板 | 换台后显式拉新频道的节目单 + 写 keep | `id` 重建**不保证**外层的 `.task` 重跑（换台只改子视图身份），所以这两件事都显式写，不指望副作用 |

另两条本项目自己的取舍：

1. **换台范围 = 用户眼前那份列表**：普通分组就是该组的频道，**收藏分组就是收藏的频道**（在收藏里换台
   就只在收藏里循环），从「继续观看」进去则是该频道**所在分组**的频道 —— 与列表所见一致，不会切到
   列表里看不到的频道。
2. **未做**：跨分组换台（上游有 `across` 之类的入口）、按频道号直接跳台、手势换台。
   → 后两项分别在 M07d-6 与 **M07d10** 补上（跨组与跳号走频道菜单，手势只换台）。

## 四、验收

- 本机自检：`check_swift.py` + `scan_report.py`（0 条真问题）。
- CI：**全绿**（`d5d2cab`，含 `Unsigned IPA` 的设备包构建），见第六节。
- 人工（需真机 / Mac）：
  1. 进任意频道 → 工具栏左上角有「上一台 / 下一台」，切到下一个频道立即换流（不是继续播上一条地址）；
  2. 切到分组最后一条再点「下一台」→ 回到该组第一条（环形）；
  3. 分组里有「没有地址」的频道（界面上点不动的那种）→ 换台会跳过它；
  4. 在「收藏」分组里换台 → 只在收藏的频道之间循环；
  5. 换台后退出到列表 → 「继续观看」是刚才换到的那一台；列表里它带「上次」标记；
  6. 只有一条可播频道时两个按钮是灰的（点了也没反应、不报错）。
