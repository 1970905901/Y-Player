# M03P22 播放页信息区补齐：解析来源 / desc / 收藏（顺手修「清了但没人调」）

- 状态：**已实现**（本地静态闸门全绿；纯接线 + 界面，无新单测 —— 相关纯逻辑已有单测）
- 时间：2026-10-10
- 触发：`AppModel+PlaybackInfo.swift` 里那两句话（M09d 写的「用户在**播放页**能直接看到
  『这集是谁解的』」）其实只出现在**设置 → 播放**那一页；另外 `clearPlaybackInfo()` 写好了
  从来没人调（M03P18 那类「断了线」的同族）。
- 依据：`VideoActivity` 控制条上的 `keep`（收藏 / 追剧）、`control.info`（播放信息）。

## 一、做法

| 件 | 之前 | 现在 |
| --- | --- | --- |
| 「解析：xxx」与站点 `desc`（`AppModel.playbackInfoRows`） | 只在「设置 → 播放」那一页显示 | 播放页信息区「媒体」一块**也显示**（空的不进列表，规则在模型里、有单测） |
| 收藏（追剧） | 只有详情页工具栏有 | 播放页信息区「追剧与下载」一块一个开关 —— 回写口由详情页给（它才握有完整元数据：封面 / 线路 / 集名） |
| `clearPlaybackInfo()` | 定义了没人调 | 三处宿主的 `onStart` 里调用（与清弹幕 / 字幕同一处）—— 不然换片会把上一部的「解析来源」带过来 |

「离线下载」那一块改名「**追剧与下载**」（收藏与下载都是「对这部片的操作」，放一起）。

## 二、口径

- 播放页**不认识 `AppModel`**：三样东西（行 / 收藏状态 / 收藏开关）都由宿主传进来 ——
  与弹幕 / 字幕 / 线路同一套做法；
- 收藏开关**没有回写口就不摆**（`onToggleFavorite == nil`）—— 与弹幕开关同一条规矩；
- 收藏的**元数据由详情页出**：`SitePlayEpisodeView` / `ParsePlaybackView` 只转发详情页给的闭包 ——
  不能让播放页自己拼一个「没有封面」的收藏把详情页存的那份盖掉。

## 三、故意没做

- **播放页里的「换源」**（跨站切换）：上游也在详情页做（我们的 M02P8 同）——不在播放页里再开一个入口；
- **信息行的长按复制 / 分享**：不做；
- **收藏分组 / 追剧列表里的排序**：那是「追剧」页的事（M02P11），与这一笔无关。

## 四、验证点（Mac）

1. 走 js2p / 解析链的片：播放页「媒体」一块能看到「解析：xxx」和站点给的说明（以前只有设置页有）；
2. 换一部**没有**解析信息的片 → 那两行**不出现**（不会把上一部的带过来）；
3. 播放页「追剧与下载」里点收藏 → 详情页工具栏的心也跟着亮（同一份收藏），再点一次取消；
4. 收藏之后去「追剧」页：封面 / 线路 / 集名都在（不是空壳）。
