## 一、为什么资产里一条规则都没有

上游的内置规则包**本身就是空的**（`{"schemaVersion": 2, "packageId": "webhtv-builtin-hls", "version": 1, "rules": []}`）。
这不是没做完，而是他们的维护规则决定的：

1. 内置规则**必须默认关闭**（`enabledByDefault: false`）；
2. 收录前要同时具备「该删」和「不该删」两侧的样本证据（fixture）；
3. 规则 id 是**永久身份**：以后改进匹配条件只升 `version`，不改 id；
4. 域名与广告时长都会变，没有持续命中率 / 误杀率数据就不该默认开。

也就是说：**内置集是「有证据才进」的地方，不是「收集得越多越好」的地方。**
所以这一轮的交付物不是规则，而是**路径与契约** —— 以后加规则是改一个 JSON 文件，不用动代码。

## 二、契约

| 项 | 约定 |
| --- | --- |
| 资产位置 | `Packages/CatVodCore/Sources/CatVodCore/Resources/hls_rules.json`（`Package.swift` 里 `.copy("Resources")`） |
| 形状 | `schemaVersion: 2` / `packageId` / `version` / `rules[]` —— 解析交给 `HLSAdRulePackage.parse`，**只认 schema 2** |
| 失败降解 | 读不到资产、坏 JSON、版本不认识 —— 一律当**空包**（内置规则出问题不该把播放路径拖下水） |
| 缓存 | `static let`（懒加载一次；上游也是 `volatile` 缓存一份） |
| 状态键的源标识 | `包 id@版本`，即 `yplayer-builtin-hls@1` |

源标识里带版本是有意的：规则 id 才是永久身份（上游规矩：改条件只升版本、不改 id），
所以**开关跟着规则 id 走** —— 包升级之后同一条规则的开关仍然有效，这正是想要的。

## 三、接线

`refreshAdRules()` 现在合并三个来源，顺序固定：

1. **内置包**（`HLSBuiltinRules`）→ 走 `resolveEnabled`：本地开关 > `enabledByDefault` > 关；
2. **接口的 `hlsRules`** → 走 `resolveInterfaceEnabled`：本地开关 > 规则自己写的 `enabled`；
3. **解析规则的 `exclude` 兜底**（`SniffRule.compiledAdRule()`）→ **不参与开关**（那是接口自己的解析规则）。

两种「基准」刻意分成两个函数、两张测试分别钉：混用的后果很隐蔽 ——
包规则会变成「包作者写 `enabledByDefault: true` 就自动生效」，用户会突然被删片段。

界面：设置 → 播放 → 广告清理规则，新增「内置规则包」一节（与接口规则复用同一行样式：开关、「已改」标记、
左滑「恢复默认」）；概览改成「内置 N 条 / 接口 M 条；当前 K 条生效」。

## 四、加一条内置规则要做什么（维护流程）

1. 备齐证据：一个**该删**的 manifest 样本（脱敏）、一个**相同时长但没有广告边界**的反样本、
   一个**错误 playlist host** 的反样本；
2. 往 `hls_rules.json` 的 `rules` 里加：`id`（`builtin.hls.<来源>.<用途>` 形状）、`name`、`version`、
   `enabledByDefault: false`（**必须**）、作用域（`playlistHostSuffixes` / `playlistHostRegex` 至少一个）、
   信号（`hostSuffixes` / `segmentUrlRegex` / 时长区间 / `requireDiscontinuity` / `requireCrossDomain`）、
   `minimumSignals`（落在 `1...信号数`）；
3. 把两类 fixture 补进 `HLSManifestCleanerTests`；
4. 跑测试 —— 下面这几条会主动拦：

| 断言（`HLSBuiltinRulesTests`） | 拦的是什么 |
| --- | --- |
| 资产能解析、`schemaVersion == 2` | 改坏 JSON、写错版本 |
| 规则集当前为空 | 提醒「空是有意的」，别以为漏了 |
| 每条规则 `enabledByDefault == false` | 违反上游第一条门槛 |
| 规则 id 唯一 | 复制粘贴时忘了改 id |
| 每条规则 `compile()` 成功 | 作用域/信号/`minimumSignals` 配错 |
