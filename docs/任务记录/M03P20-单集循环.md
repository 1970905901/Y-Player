# M03P20 单集循环（对齐上游控制条的 `repeat`）

- 状态：**已实现**（本地静态闸门全绿 + 新单测；Mac 编译 / 测试 / 上机待 YG）
- 时间：2026-10-10
- 触发：上游播放页动作栏里有一个「循环」（`control.action.repeat` → `onRepeat` → `player.setRepeatOne`），
  我们一直没有 —— 短剧 / 挂机 / 反复看一段的场景只能手动拖回去。
- 依据：`VideoActivity.onRepeat`（`player().setRepeatOne(!player().isRepeatOne())`）、
  `PlayerManager.setRepeatOne`（上游做在内核层：ExoPlayer 的 repeat mode）。

## 一、上游口径 → 本项目

| 上游 | 这里 |
| --- | --- |
| `repeat` 按钮切换单集循环 | 播放页信息区「播放」区一个 Toggle「单集循环（播完回到本集开头）」；**只给点播**（直播没有进度记录，循环没有意义） |
| 循环做在**内核层**：播完根本到不了 `ended` | 做在**播放页这一层**：`ended`（或到片尾标记）之后 `seek(0) + play()` —— 三个内核都吃得到，不用各改一遍 |
| 与片尾标记的关系：上游仍会按片尾跳下一集（循环在内核、片尾逻辑在外层） | **循环优先**：开着循环时片尾标记只把它带回开头（`endAction(isRepeatOne:hasNextEpisode:)`，纯函数、有单测） |
| 不落盘（每次播放会话一个开关） | 同：页面内偏好，不进进度记录 |

## 二、口径

- **循环 ≠ 重播**：不写「看完」标记，只把进度条拉回 0 接着播（与「从头播放」那个按钮是两回事）；
- 循环、连播（M12P1）、片尾标记（M03P16）**共用一个出口**（`endAction`）—— 优先级只写在一个纯函数里；
- 直播页不出现这个开关（没有进度记录）。

## 三、故意没做

- **列表循环 / 随机播放**（上游也没有）：只有单集循环这一档；
- **循环次数 / 间隔**：不做；
- **落盘**：见上（要「记住」的话与倍速 / 画面比例是两条不同的口径，等有人提）。

## 四、验证点（Mac）

1. 放一集 → 打开「单集循环」→ 等它播完 → **回到开头接着播**（不切下一集、不出现结束态）；
2. 关掉循环 → 播完按原来的规矩走（有下一集连播；最后一集停在结束态）；
3. 标了片尾（M03P16）的集 + 开循环 → 到片尾标记时**回开头**，不是切下一集；
4. 直播页**没有**这个开关。
