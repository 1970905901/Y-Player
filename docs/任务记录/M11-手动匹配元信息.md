## 一、数据：`TMDBMatchBook`（纯逻辑，CatVodSource + 单测）

「片名 → 该用 TMDB 的哪一条」，一行一条落盘：`百分号编码的片名|movie:123`。

- **片名先百分号编码**（`CharacterSet.alphanumerics`）：片名里出现 `|` 或换行
  （站点给的名字什么都有）时，分隔符不会被撕开；
- **解析是逐行的**，与 `TMDBConfig` 那种「字段数不对就整条作废」**故意不同**：
  一行坏记录只丢那一行，其余照留 —— 用户手配过的东西不该被别的片名连坐；
- `TMDBMatchKey(storageToken:)` 认不出 kind、或 id 不是正数就给 `nil`：
  宁可不匹配（回落自动搜），也不拿一个错 id 去请求；
- 落盘串**按片名排序**（同表同串，便于比对与测试）。

`AppModel` 侧只有四件事（`AppModel+Metadata.swift`）：

| 成员 | 作用 |
| --- | --- |
| `tmdbMatchBook` | 读写落盘（空表时**删键**，与 `tmdbConfig` 同一条路） |
| `tmdbMatchKey(for:)` | 查这一片有没有手动匹配（片名去空白归一） |
| `tmdbMatchToken(for:)` | `auto` / `movie:123` —— **当加载键用** |
| `setTMDBMatchKey(_:for:)` | 落库 + **当场作废这一片的会话缓存与在途请求** |

`performTMDBLookup` 里**手动匹配优先**：指定了就 `details(kind:id:)`，**不再搜**
（这一层存在的意义正是「自动搜出来的不是我要的」）。

## 二、界面：`TMDBMatchSheet`

⋯ 菜单里点开，半屏面板（`adaptiveHalfSheet()`），三块：

1. **当前**：片名 + 现在的来源（`手动 · 剧集 · 1234` / `自动（按片名搜）`）+「恢复自动匹配」；
2. **搜索 TMDB**：关键词输入（默认填片名）+ 搜索按钮；没配 key 时写明去哪儿配；
3. **候选**：海报缩略图 + 标题 + `电影/剧集 · TMDB id` + 两行简介，**点一条就生效并关面板**。

约定：**选中即生效**（不像「筛选站源」要 ✓ 应用 —— 这里一次只改一条记录，
没有「批量改动要不要提交」的问题）；点一条就落库 + 关面板。

**重拉靠加载键，不靠通知**：详情页顶部与选集卡片两个 `.task(id:)` 的键都拼进了
`tmdbMatchToken`，选完新匹配，两处各自重拉 —— 不用谁去通知谁。

## 三、故意没做

- 不做「TMDB 里搜到但没背景图」时的额外兜底（`TMDBPosterSet` 已有的三级回落够用）；
- 不做手动匹配的**批量管理页**（列表 / 清空）：目前只在「撞到刮错的那一片」时用，
  真要管理，把值当普通偏好清掉即可；
- 不做「保存成别名表 / 自动学习」：那是另一件事，且要小心把一次纠错泛化成错误规则；
- 不做 TTL / 失效：与元信息缓存的既定口径一致（进程内会话缓存，重启即失效）。

## 四、验证点（Mac）

1. 详情页（Emby 视图）⋯ →「手动匹配元信息…」：面板出来，片名与「自动（按片名搜）」都对；
2. 没配 TMDB key 时：搜索框置灰 + 一行写明去「设置 → 播放 → 播放页」配
   （**不该**是点了没反应）；
3. 配了 key：搜「仙逆」→ 出候选（有图 / 有 `电影·剧集` 与 id）→ 点一条 →
   面板关掉，**顶部大图与选集卡片当场换成那一条的图**，标题与简介也换成它的；
4. 重进这一片：手动匹配还在（落盘过）；
5. 面板里「恢复自动匹配」→ 回到自动搜的结果。
## 五、Mac 首验踩的两处（`f9ae3b1`）

1. **iOS-only API 混进跨平台包**：`TMDBMatchSheet` 里直接写了
   `textInputAutocapitalization(.never)` 与 `disableAutocorrection(true)` ——
   `CatVodUI` 是跨平台包，`swift build` 走 macOS，当场编译不过。
   仓库早有 shim：`platformTextInputAutocapitalizationNever()`（`PlatformShims.swift`）
   + `autocorrectionDisabled()`。**新增输入框一律用这两个，别再直写。**
2. **归一没做全**：`TMDBMatchBook` 原先只在 `setKey` 里去空白，
   `key(for:)` 与两个 `init` 都不去 —— 单测里「片名前后空格归一」那条直接红。
   现已收成 `normalizedTitle(_:)`，**写 / 查 / 还原三处都走它**。
