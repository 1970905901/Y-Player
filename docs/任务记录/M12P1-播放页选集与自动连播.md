# M12P1 播放页选集 / 下一集 / 片尾自动连播

- 状态：**已实现**（本地静态自检过；真机由 YG 用 Mac 验证）
- 时间：2026-10-09
- 起因：追剧体验的硬伤 —— 一集放完就停在结束态，想接着看必须退回详情页再点一次；
  播放页也没有「选集」入口（`PlayerEngineKind` 支持换集，骨架早就有了，缺的是接线）。

## 一、设计：播放页不认识站点

播放页（`PlaybackView`）只收值 + 闭包（这个设计从 M2 就在），所以换集能力也走同一条路：
**详情页**把「第 i 集怎么变成资源」包成 `PlaybackPlaylist` 传进来：

| 字段 | 作用 |
| --- | --- |
| `episodes` / `currentIndex` | 「选集」抽屉画什么、当前高亮哪一集 |
| `loadResource: (Int) async -> PlaybackEpisodeResource?` | 换集的路子（异步：js2p/type=4 要先去站点换地址） |
| `onIndexChanged` | 换集回传口（宿主据此更新进度键里的集下标等） |

`PlaybackEpisodeResource` = 资源 + **进度上下文** + 标题：换集后三者都要跟着换，
否则「上次看到」会指回旧集、导航栏与「下载本集」还写着上一集。

`PlaybackView` 里对应的三样从 `let` 改成了 `@State`（`activeResource` / `activeProgressContext` /
`activeTitle`）—— 这是这一片唯一的「破坏性」改动，调用点没变（init 参数名照旧，新增的
`playlist` 带默认值 nil，直播 / 下载播放 / 设置页试播这些入口一行都不用动）。

## 二、三种集三条路（详情页 `episodePlaylist`）

1. **直链**（type 0/1/2）：`makeResource(for:)` 同步造；
2. **要向站点/宿主换地址**（type 3/4）：`siteResource(site:episode:)` 异步换
   （与 `SitePlayEpisodeView` 同一条路，但**不**处理「还要再解析一次」）；
3. **需要解析链的集**：`loadResource` 返回 nil → 播放页提示「请回详情页点它」——
   解析链要换页面、要等 Web 嗅探，不适合在播放页里悄悄切。

## 三、界面

- 播放页信息区多一个「**选集**」区：`选集（共 N 集）` 打开抽屉（复用详情页那套
  `EpisodeListDrawer`，半屏）、有下一集时给一行 `下一集：第 N 集`；
- **片尾自动连播**：`.ended` 且还有下一集就自动换（最后一集停在结束态等人）；
- 换集后：进度/时长/轨道/续播提示/错误全部清零重来，弹幕**按新集名重新搜**
  （`onDanmaku?(DanmakuRequest(name:episode:))`）。

## 四、故意没做

- **连播开关**：现在默认连播（与上游一致）；要「播完停住」的人在设置里还没有开关，
  等有人提再加（加的话进「设置 → 播放」）；
- **解析链集在播放页换集**：见第二节第 3 条（回详情页是刻意的）；
- **换集动画/预告**（「3 秒后播放下一集」那种）：直接换，简单可预期；
- **字幕 cue 换集**：字幕走 M09 的取用链（`AppModel.loadSubtitles`），`siteResource` 里会为
  新集重新取；直链站点本来就没接字幕链（与首播一致）。

## 五、验证点（Mac）

1. 详情页选**中间**某一集播 → 播放页「选集」区出现 `选集（共 N 集）` 与 `下一集：…`；
2. 点「下一集」→ 直接换集播放（不退回详情页），标题/进度/弹幕都跟着换；
3. 点「选集」→ 半屏抽屉，点任意一集 → 播放页就地换过去，当前集高亮跟着走；
4. 让一集**放到自然结束** → 自动进下一集；最后一集播完停在结束态（不循环）；
5. js2p（type 3）站点同样可用：换集会重新向宿主换播放地址（稍等一下出现画面）。
