# M06o 本地代理：开关与服务同步（关了真的停、开了当场起）

- 状态：**已实现**（本地四闸门全绿 + 新单测；Mac 编译 / 测试 / 上机待 YG）
- 时间：2026-10-10
- 触发：接手前的孤儿方法审计 —— `AppModel+LocalProxy.swift` 的 `stopLocalServer()` 从 M06b 落地起
  **一个调用方都没有**（与 M03P18 的「四个参数从来没人传」同一类断线：编译过、单测绿、上机才看得见）。
  两个后果：①设置 → 播放里关掉「本地代理注入 header」，监听 socket 还挂在回环上、设置页那行说明
  还是「运行中」；②`ensureLocalServer()` 的注释写着「回到前台需要再 start 一次」，
  但 `RootView` 的前台回调只恢复了下载，从没调它。

## 一、做法

1. **开关是服务的总闸**（`AppModel.isLocalProxyEnabled` 的 `didSet`）：关 → 停、开 → 起。
   `didSet` 是同步的、起停是异步的（`LocalHTTPServer` 的 `start()` / `stop()` 都是 actor 方法），
   所以 `didSet` 里丢一个 Task —— 与 `applyLogPreferenceToHost()`（日志开关 → 宿主落盘）同一套做法。
2. **一个对账入口** `syncLocalServerWithSwitch()`：**以开关当前值为准**，而不是「按事件做事」——
   `ensureLocalServer()` / `stopLocalServer()` 仍是两个原语，对账只决定用哪个。
   调用方三处：开关的 `didSet`（经 `applyProxySwitchToServer()`）、`RootView` 的冷启动
   （原来调 `ensureLocalServer()`，换成它）、`RootView` 的回前台（新增，兑现上面那句注释）。
3. **对账串行**（`AppModel.localProxyLifecycle`）：`LocalHTTPServer` 这个 actor 在 `await` 处会重入 ——
   两路并发（连点开关、回前台撞上点开关）各进一次 `start()` 时会各绑一个端口，先绑的那个
   就此成了**没人管的监听**。串行 + 「执行时才读开关」⇒ 不管排队里积了几次，最终态都跟开关一致。
4. **`stopLocalServer()` 去掉早退**：没有服务在跑时也把说明复位（关掉开关后不该还留着上一次的
   失败文案）。两个原语都是幂等的（`LocalHTTPServer.stop()` 本身也幂等）。

## 二、口径与取舍

- **开关关着 = 服务不起**：冷启动时开关是关的，`ensureLocalServer` 本来就不起（M06b 定的），
  这次只是把「运行中 → 关」这一半补上；
- **正在播的代理流会被停掉**：用户关开关时如果 PiP 里还挂着一条走 `/proxy` 的流，它会断。
  这是**故意**的：开关的语义是「本机服务总闸」，只绕开、不停止正是这次要修的坑；要更温柔
  （「播放页开着就先留着」）得先有「播放页是否活着」这个状态，本片不做；
- **幂等**：开着再开一次直接返回原端口（`start()` 的老行为），关着再关一次只是复位说明；
- **说明文案**：关 = 「本机服务已停止（需要 header 的 HLS 源可能播不了）。」——
  与 `ensureLocalServer` 在开关关着时给的「本地代理已关闭：…」各说各的场景（「刚停」/「启动时就没开」），
  两句都是实话。

## 三、故意没做

- 进后台自动停：iOS 挂起时本来就不收请求，回前台已经会重新对账；停 / 起反而多一次端口绑定；
- 「播放中不打扰」的温柔策略（见上）；
- 把 `ensureLocalServer()` 删掉：它是「只管起」的原语，播放侧以后要「开播前再确保一次」还用得上。

## 四、验证点（Mac）

1. `swift test --package-path Packages/CatVodUI`：新三条 ——
   「关掉开关：服务当场停、端口清掉、说明改成「已停止」；再打开又能起来」（真的绑端口、看端口在不在）、
   「开关本就关着：对账不去起服务，也不谎报「运行中」」、
   「翻开关本身就走对账（`didSet` 那条路）」。**新增了测试文件**，跑之前先 `rm -rf Packages/*/.build`；
2. 全包测试 + App 编译照旧（Mac 命令块见交接文档第六节）；
3. **上机**：设置 → 播放 → 关掉「本地代理注入 header」→「本机服务」那行当场变「已停止」；
   再打开 → 当场变「运行中：127.0.0.1:****」（不用重启 App）。然后播一个带 header 的源确认照旧。

## 五、教训（写给下一次）

- 「定义了但从没被调用」的方法要当真：`stopLocalServer()` 和 `ensureLocalServer` 注释里的
  「回前台再 start 一次」都是**意愿**，不是事实 —— 审计孤儿方法时别只看「它被别处调过没有」，
  还要问「这个意愿有没有接线」（同 M03P18）；
- 给 actor 写「幂等 start」时，幂等的范围是**顺序调用**：内部有 `await` 的话，并发调用不幂等
  （会绑两次端口）。要并发安全就得像这里一样在外面排队，或者在 actor 内保存 in-flight Task
  （`CatSpiderInitializer` 的记忆法）。
