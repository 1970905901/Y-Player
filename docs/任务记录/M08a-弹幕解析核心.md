# M08a 弹幕解析核心（搜索地址 / 来源 / 弹幕行）

- 状态：搜索地址策略、来源解析、弹幕文件解析都已实装并有单测；**下载接线与渲染**是后续两笔（见第四节）
- 时间：2026-10-09
- 依赖：上游 `api/DanmakuApi.java`、`bean/Danmaku.java`、`bean/DanmakuData.java`

## 一、为什么先做这一半

矩阵那一格写着「模型 + 解析，渲染待 M8」—— 核了一遍才发现**连解析都没有**：
全仓库只有一个 `DanmakuAPIConfig`（设置页把四个地址槽存下来）。也就是说弹幕这条链在 iOS 侧从零开始。

它天然分成两半：**拿到弹幕行**（纯逻辑：地址策略、宽容解析、字段判法）和**把行画到屏幕上**（UI）。
前一半完全可测、也不依赖模拟器，所以先落它 —— 后一半等能跑一轮真实设备/模拟器再动。

## 二、三块契约

### 1. 搜索地址（`DanmakuAPI`）

用户填的那一个地址里藏了两种约定：

| 地址形态 | 请求 |
| --- | --- |
| 含 `{name}` / `{episode}` | 百分号编码替换后 **GET** |
| 其它 | 先按 `getSearchUrl` 推出搜索地址，再 **POST** 表单（`name` / `episode`） |

`getSearchUrl` 三条规则：末段已是 `danmaku`（大小写不敏感）→ 原样；路径**超过一段**（如 `/api/v1`）→ 原样；
否则补一段 `/danmaku`。补错这一段，请求会打到一个不存在的接口上 —— 现象是「弹幕一直加载失败」，
而日志里的地址看着还挺正常，所以三条都单写了用例。

### 2. 来源解析（`DanmakuSource`）

搜索响应返回的是一批**候选来源**（每条的 `url` 指向真正的弹幕文件），形状五花八门。
上游 `arrayFrom` 的宽容度必须照抄，否则「能用的源」会悄悄变少：

- JSON 数组 → 逐项；
- 裸字符串 → 当一条来源（`url` 就是它自己）；
- 对象 → 先看 `data` / `list` / `result` / `results` / `items` / `danmakus` / `danmaku` 里有没有数组；
- 其它对象 → 当一条来源；
- 字符串以 `[` / `{` 开头 → 再当 JSON 解一次；
- 没有 `url` 的项丢掉。

### 3. 弹幕行与文件（`DanmakuLine` / `DanmakuDocument`）

参数串是经典 B 站格式 `p="出现时间,类型,字号,颜色,…"`（至少 4 段，后面几段不关心）：

- 颜色**强制补成不透明**（`0xFF000000 | value`）；
- 描边照抄上游的判法：颜色**数值**不大于纯黑用白、否则用黑。这条很粗（`#111111` 会拿到黑描边），
  但照抄是有意的 —— 自己「改良」会让同一份弹幕在两端看起来不一样；
- 文本只反转义四种实体（`&amp;` / `&quot;` / `&gt;` / `&lt;`），与上游一致；
- 坏行返回 nil：一行参数写坏不该让整份弹幕作废；
- 文件解析**手写扫描** `<d p="…">文本</d>`：按时间排序、坏行跳过、末尾截断尽量把已解析的给出来、
  自闭合标签跳过。不用 `XMLParser` 是有意的 —— 几万条的文件里，容错比 SAX 的能力更重要。

## 三、测试

- `DanmakuAPITests`：模板走 GET（含百分号编码）、基地址走 POST（含表单字段）、
  `getSearchUrl` 三条规则、表单编码（空格 `+`、键排序）、空地址不给请求；
- `DanmakuLineTests`：来源五种形状 + 过滤 + 退化输入（空 / 非 JSON）；
  行参数、描边判法、位置类型（1/4/5）、实体反转义、坏行；
  文件排序、坏行跳过、末尾截断、自闭合。

## 四、遗留

1. **下载接线**：拿到候选来源后真要下载弹幕文件 —— 走既有 `HTTPTransport` 即可（含 header 注入与代理），
   属机械接线；
2. **渲染**（上屏、轨道避让、时间同步、描边绘制）—— UI 层，等能在设备/模拟器上验一轮再做；
3. **标题匹配**：上游有一套标题候选链（手动标题 → `MediaTitleResolver` → 清洗后标题 → AI 兜底），
   其中 `MediaTitleResolver` 依赖 TMDB（后置项）。本项目先不做这一步：
   用户填的地址 + 播放页的片名/集名直接搜，够用；
4. **简繁转换**（上游 `Trans.t2s`）不做：需要一张转换表，值不值另说；目前只去首尾空白。
