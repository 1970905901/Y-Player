## 三、现在最要紧的一件事：上机验收（四件）

自研 FFmpeg 内核（设置 → 播放 → 内核选「自研 FFmpeg」）**只确认过「有声音**」——
第一轮上机是「有声音没画面」，之后连着修了四轮，但**画面 / 字幕 / 换轨都没被确认过**。
另外这轮又加了三条只能上机验的东西。

1. **自研内核**：模拟器上先把「解码方式」手动选成**软件解码**（模拟器没有 VT 硬解，选硬解会明确报错 —— 设计如此）。
   一次过：画面出来 → 播放信息（**输出** `420v`，10bit 片源 `x420`；带 `SDR · …`）→
   拖进度 / 暂停 / 音量 / 倍速 → 换音轨（多轨片源）→ 内嵌字幕（带文本字幕轨的本地文件）→
   慢源卡顿时显示「**缓冲中**」且进度停住；
2. **轨道名（M03P8）**：多音轨 / 内嵌字幕的片源，「轨道」下拉框应显示 `zh` / `简体` 这类名字（没有元数据的照旧「音轨 2」）；
3. **大文件直链（M06n）**：带 header 的 >32MB 直链走 `/proxy` 应能一直播（以前会在 32MB 处 502）；
4. **加密 / 字节范围下载（M10k / M10l）**：清单带 `#EXT-X-KEY:METHOD=AES-128` 或 `#EXT-X-BYTERANGE` 的源下一集 —— 以前立刻失败，现在应能下完并本地播；
   顺带验 **M10m 暂停 + M10n 续下**：HLS 一集下到一半点「暂停」→ 立刻停住、状态停在「已暂停」；
   点「继续」→ **不从头下**（下过的片段不再取，完成得比首跑快）；完成后文件能本地播。
5. **直链续下（M25P2）**：下一个直链（mp4 / 大文件）到一半点「暂停」→ 文件留着、状态「已暂停」；
   点「继续」→ 只取剩下的（进度从已下字节接着走），完成后文件能本地播；
6. **片头 / 片尾（M03P16）**：播到片头结束处标「片头」→ 退出重进应从那儿起播（提示「已跳过片头」）；
   标「片尾」→ 播到那儿自动进下一集；离两端远时「标记当前」是灰的（细节见 `M03P16-片头片尾.md`）；
7. **换线路（M03P17）**：多线路的片，播到 5 分钟换另一条线路 → 接着播（不是从头）、标题不跳；
   换到没有这一集的线路 → 提示并留在原线路；返回详情页 → 线路停在刚看的那条上；
8. **弹幕 / 字幕（M03P18）**：有弹幕的片，弹幕**要真的上屏**、暂停会停；设置里的
   字号 / 透明度 / 速度 / 区域改了要**跟着变**；总开关关掉整层消失（播放页与设置页两处一致）；
   有 `subs` 的源，字幕要真的上屏（换集后字幕会消失，这是已知缺口）；
9. **画面比例按片记忆（M03P19）**：一部片切到 4:3 后退出再进 → 还是 4:3；换另一部片 → 是「适应」；
10. **单集循环（M03P20）**：开着循环 → 播完（或到片尾标记）回到本集开头，不切下一集；
    关掉 → 按原来的规矩连播 / 停在结束态；直播页没有这个开关；
11. **锁屏（M03P21）**：自绘内核控制条右端的锁按钮 → 锁上后双击 / 拖动 / 长按 / 捏合全不响应、
    只剩锁按钮可点；退到后台回来自动解锁；系统内核没有这个按钮；
12. **播放页信息区（M03P22）**：解析链的片，「媒体」里能看到「解析：xxx」与站点说明（换没信息的片就不出现）；
    「追剧与下载」里能收藏 / 取消（与详情页的心同步，「追剧」页里封面线路集名都在）；
13. **播放页手势（M03P12 / M03P13 / M03P14）**：先把播放页的「长按倍速」调到 3.0x，再在自绘内核上长按 0.5 秒
   → 提示 `3.0x` 且松手回原倍速、按住期间拖动不生效、松手不闪控制条；左半屏纵向拖 = 亮度、
   右半屏 = 音量；双指捏合 → 「缩放 N.x」、捏回 1.0 归位（改画面比例也会归位）。
   细节见 `M03P12-长按加速与分区手势.md` / `M03P13-长按倍速可调.md` / `M03P14-双指缩放.md` 的验证点。
14. **本地代理开关（M06o）**：设置 → 播放 → 关掉「本地代理注入 header」→「本机服务」那行当场
   变「已停止」；再打开 → 当场变「运行中：127.0.0.1:****」（不用重启 App）；带 header 的源照旧能播。
   注意：关的那一刻如果 PiP 里还挂着走 `/proxy` 的流，它会断 —— 这是故意的（开关就是总闸，
   见 `M06o-本地代理开关与服务同步.md`）。
15. **上滑 / 下滑切集（M03P23）**：多集片、自绘内核 —— 画面**中间**快速上滑 = 下一集、下滑 = 上一集；
   同一区域**慢慢**上下拖仍是音量 / 亮度；**左 / 右四分之一**里快速上下甩只调音量 / 亮度、不切集；
   到头了（第一集 / 最后一集）再甩给一句提示。细节见 `M03P23-上滑下滑切集.md` 第四节。
16. **播放页「弹幕设置」（M03P24）**：有弹幕的那一集 →「弹幕设置…」开半屏面板 ——
   拖字号 / 透明度 / 速度 / 区域，屏上弹幕**当场**跟着变；「恢复默认」把四项拉回默认、**弹幕仍开着**；
   面板里调完，回「设置 → 播放 → 弹幕显示」看到的数值一致（同一份配置）。
17. **播放页「选择弹幕」（M03P25）**：有候选的那一集 →「选择弹幕…」—— 点另一条候选，
   屏上弹幕**当场换**；「重新搜索」改个名字再搜，候选里多出新条目；换集回到自动、
   同一集换线路选择保留。细节见 `M03P25-播放页选择弹幕.md` 第四节。
18. **直播页纵甩换台（M07d10）**：直播页（自绘内核）—— 中间快速**上滑** = 上一台、**下滑** = 下一台
   （与点播相反，上游默认）；工具栏那颗 `arrow.up.arrow.down` 点亮后方向反转（重启仍反转）；
   慢慢上下拖 / 侧边四分之一里的纵甩仍是音量 / 亮度。细节见 `M07d10-直播手势换台.md` 第四节。

**M04P2 的 HDR 验收**（色彩 / 输出两行）：要 HDR 片源 + 硬解那条路，模拟器走不通，得真机 —— 这条一直挂着。

## 四、M04 线的来龙去脉（自研 FFmpeg 内核）

M04P4 探针 → P5 引擎骨架 → P6 输入层 → P7 VT 硬解 → P8 帧→样本/渲染器 → P9 视频闭环 →
P10 音频 → P11 音视频接线 → P12 seek → **P13 UI 接线** → **P14 软解兜底** → P15 播放信息补齐 →
P16 换音轨 → P17 时钟跟着帧走（缓冲）→ P18 软解转 420v → P19 内嵌字幕（文本轨）→ P20 输出侧色彩标签 → **P21 软解 10bit（P010 → x420）**。

关键口径（写在代码注释里，改之前先读）：

- **可用性**：`.ffmpeg` = 引擎实装 + Libav 六件套齐；两个自绘内核都在 `makeEngine` 时**要画面层**，没给就返回 nil；
- **解码方式手动选、不自动降级**（YG 拍板）：硬解不可用 = 明确报错让你改设置，libav 中途掉回软解也算失败；
- **时钟跟着帧走**：饿（时钟超过最后一帧 0.3s）就停表 + 报「缓冲中」，有帧再接回去 ——
  别让时钟跑到数据前面（那会变成「卡完快进一段」）；
- **只报真能用的**：字幕只报文本轨；轨道清单只在开片报一次（重报会把用户的选择复位成「自动」）；
- 软解是**兼容路线**：8bit 源走 420v、10bit 源走 x420（M04P21）；源声明了色彩就按源挂 CoreVideo 标签（M04P20），声明不出来才吃默认（HDR / 画质靠硬解那条）。

## 五、故意没做 / 挂着的（别以为漏了）

- 字幕：**位图轨**（PGS / DVD）、**ASS 样式**（libass）不做；内嵌字幕只有流下标，没有语言 / 标题；
- 软解：10bit 已直通（M04P21：P010 → x420）；色彩附件已接通（M04P20）；**不做色彩转换 / tone mapping**；矩阵只挂不读回；10bit 的 4:2:2 / 4:4:4 不做；
- 播放器：换轨后**不重定位**（从当前位置往后接）；逐帧步进 / 音频增益没做；显示侧丢帧没有读法；
- 内核：KSPlayer / VLC 两条路线已被否决并留档（`M04P5` 文末），别再提；
- 下载：**SAMPLE-AES** 仍如实拒绝（要 CENC 取样解密）；字节范围**缺起点**（不合 RFC 8216）的清单也拒 —— 其余的范围片段已在 M10l 支持；**断点续下已做**（M10n：HLS 有账目；**直链不续**，整份重下）；
- 代理：落盘文件靠「15 分钟宽限 + 每次请求顺手清」控制占用，**没有磁盘配额**；边下边发没做（M06n）；
- 轨道名：**不做语言码映射**（`zh` / `chi` 原样显示）、不标默认轨（有「自动」就够）——M03P8 记过。

## 七、坑列表（都踩过，别再踩）

1. **本机没有 Swift 编译器**：三个 Python 闸门 + SwiftFormat **抓不到编译错误**。
   改完代码必须让 YG 跑 `swift test --package-path Packages/<包>` —— 它同时是编译闸门，比 xcodebuild 快得多。
2. **加 / 删包内文件后清 `.build`**：`rm -rf Packages/*/.build`。
   不清的话，**依赖侧**的 `swift test` 会用缓存的旧文件清单，报「cannot find type X in scope」（踩两次了）。
3. **`#expect` 里别放**：mutating 调用（宏展开成 `$0` 闭包 → 「cannot use mutating member on immutable value」）、
   `async`、闭包、复杂表达式 —— 一律先落局部 `let` 再断言（`.swiftformat` 里 `preferKeyPath` 被关掉也是这个原因）。
4. **`private` 的两副面孔**：搬进**同文件**扩展的成员可以继续 `private`（主声明照样能调，`statsSection` 就是这么用的）；
   搬进**另一个文件**就必须去掉 `private`。另外 internal 方法的签名里不能出现 private 类型。
   这两条现在有本地预检：`Scripts/check_visibility.py`（写进 `check.sh` 了）——
   第一条是 warning（可能有误报），第二条是 error（零误报）；改完扩展顺手跑一遍。
5. **SwiftLint 的 error 只有这几条会挡**：`type_body_length`（>450）、`file_length`（>800）、
   `line_length`（>200；>140 是 warning）、以及各种 opt-in 规则。前两条现在本地闸门就能抓。
6. **libav 的导入类型别猜**：`AVCodecContext.pix_fmt` 是 `AVPixelFormat`（比 `Int32(rawValue)`）；
   `SwsContext` 是 `UnsafeMutablePointer<SwsContext>`（前向声明结构体，**不是** `OpaquePointer`）；
   `AVERROR(EAGAIN)` 是**平台常量** `-EAGAIN`（Darwin 35，不是 11）；`AV_TIME_BASE` / `AVSEEK_FLAG_*` 等宏值写死并注释。
7. **OSLog 的插值是 escaping autoclosure**：里面引用属性要显式 `self`，而 SwiftFormat 的 redundantSelf 会删 `self.`
   —— 先落局部变量再插值（`LibavTrace` 的用法都是这么写的）。值要标 `.public`，否则日志里是 `<private>`。
8. **改中文注释要拿精确现文当锚点**（差一个字就是 0 命中）；批量替换前先断言命中数 = 1；
   文件尾要有换行（`linebreakAtEndOfFile`）。另外，在 Windows 上**生成** Swift 代码时，转义会被
   两层东西吃掉：PowerShell 双引号参数里的反引号是转义符（`` `a `` 变成响铃符）、Python 非 raw
   字符串里的 `\"` 退化成 `"`。含反引号 / 转义引号的片段，用**单引号 here-string + raw 字符串**
   落盘、再核一遍文本 —— 本地几个闸门都看不出来，只有 Mac 编译会报（M07d9 就吃了一发
   `["数组不是表"]`：转义没了，测试文件变成了数组字面量）。还有：**拼接锚点别落在声明中间** ——
   `s.find("func teardown")` 会把前面的 `public ` 留在原地、把它切给新插进来那段
   （M03P9 首验两处编译红都出自这一类）。改完把 diff 从头读一遍，别只看「闸门绿了」。
9. **push 偶发 schannel SSL 失败**：等一会儿重试即可。
10. **Core 里新加「给上层用」的工具要 public**：internal 时上层会 `cannot find 'X' in scope`
    （M10k 的 `AES128CBC` 首轮 Mac 编译就红在这）；本地闸门抓不到，改完先想一句「谁要调它」。
11. **MPVKit 的 FFmpeg 是裁剪构建**：`--disable-demuxers` / `--disable-decoders` 加白名单，
    `yuv4mpegpipe`、`rawvideo` 都没编进去 —— **测试夹具只许用白名单里的容器 / 编码**
    （M04P21 拿 y4m 造 10bit 输入，打开就失败；要查清单就翻 MPVKit 的 `ffmpegConfiguers`）。
12. **AVAssetWriter 编不了 10bit HEVC**：顶层 `AVVideoProfileLevelKey` 会被判非法 key、直接抛 NSException；
    不给 profile 又只编 8bit。夹具要 10bit 就走 `VTCompressionSession` 直编 Main10、
    再用 AVAssetWriter **直通**封 mp4（`outputSettings: nil` + `sourceFormatHint`，M04P21 踩了三轮）。
13. **别用镜像状态当循环开关**：M10m 第一版拿「镜像里这条还是不是 `running`」当「该不该开跑」
    的开关，结果任务挑了又跳、`while true` 空转烧 CPU（Mac 首验 `sample` 抓到的：主线程卡在
    `runDownloadQueue` 的 `save`，17 分钟 CPU）。当时读路径还把 `running` 降级成 `waiting`
    （条件恒假）；M25P1 已把降级挪到 `restoreDownloads()`（启动 / 回前台），但规则不变：
    镜像会被用户操作 / 恢复 / 迟到的结果改，循环的退出条件只认「还有没有可启动的任务」，
    结果的取舍按结果自身的状态分派。
14. **store 的 `save` 是离 actor 的 await，落地顺序没保证**（非隔离 async 跑在全局执行器上）：
    「读镜像 → 改 → 落库」不是原子的，两条路径各写同一状态时会抢顺序 —— M10m 的「暂停后马上继续」
    就被迟到的取消结果盖回暂停（`60e0ea8`）。规则：**同一个状态不要有两条路径各写一遍**；
    用户操作写下的状态，执行器的回执只该「别盖」（取消结果干脆不写）。
15. **拆分出去的扩展里，被主文件调用的成员不能是 `private`**：M25P2 拆 `DownloadRunner+Direct.swift` 时，
    `downloadStreaming` 写成 `private` 却由 `DownloadRunner.swift` 的 `download()` 调用 —— 编译期才报
    「inaccessible due to 'private'」。**M03P25 起这条闸门抓得到了**：`check_visibility.py` 原来只看
    「声明类型的那个文件」里的 private 成员（主文件引用扩展文件里的 private 正好漏掉 —— M03P25 又踩一次），
    现在按「类型名 + 仓库命名约定（`X.swift` / `X+yy.swift`）」把主文件与各扩展文件**互相**查
    （实测过「改回 private 就报」）。仍然是启发式：拆分时先问一句「谁要调它」，
    要跨文件的就 internal + 主文件留一行说明。

16. **消费任务被取消时，`AsyncThrowingStream` 的 `next()` 会回 nil（不抛错）**：M25P2 首验，
    直链暂停的账目全丢 —— `while let chunk = try await cursor.next()` 于是「正常」退出，
    紧接着的对账把取消当成「字节数对不上」报出去（`PartialStop` 没抛出、`receivedBytes` 回 0）。
    规则：**循环后面再补一次 `Task.checkCancellation()`**，把「取消」和「收完」分开；
    清单收集那种「正常结束 = 收完了」的循环同样要补（否则半份清单被当成没有片段写成一个假文件）。

17. **默认参数别引用 `@MainActor` 类型里的 `static`**：`AppModelFixture.load(_ json: String = …)`
    那条默认参数是在**非隔离上下文**里求值的 —— 引用主 actor 隔离的静态量是警告，
    Swift 6 语言模式下直接是错误（`AppModelFixture.defaultConfig` 就吃过这条，M03P10 首验日志里看到）。
    夹具的配置字符串这类常量放**文件级 `private let`** 就好。

18. **`async` 函数体里别直接 `lock()/unlock()`**：`NSLock` 不是 async 安全的，持锁挂起会把线程钉住 ——
    Swift 6 语言模式下这是**错误**（Swift 5 只是警告）。做法：把「进锁 → 一读一写 → 出锁」收进
    **同步**小方法，`async` 调用它们（`LibavFFmpegSession` 的那组「同步临界区」就是例子，M03P11）。

19. **SwiftUI 的 `TapGesture` 没有「按住多久就不算点按」的上限**：长按松手会补发一次**单击**
    （系统手势识别器不会像 Android 那样在长按后吞掉 tap）。长按那条别用 `exclusively` 去挡
    （长按失败才轮到点按，那时 touch-up 早过去了 → 正常单击也会失灵），用「同时识别 + 松手后
    一小段窗口里吞掉点按」（`shouldSwallowTap()`，M03P12）。另外 `@State` **只能声明在主声明里**，
    拆扩展文件时新状态加在主文件、跨文件用到的成员去 `private`（M03P12 拆手势时又走了一遍）。

20. **版本分支（`#available` / `#if os(...)`）只许出现在 `CatVodUI/Platform/` 基础件里**：
    业务视图写了就违反 `docs/UI 规范.md` 第二节 —— M03P14 的双指缩放在 `PlaybackView+Gestures.swift`
    里写过一次，M03P15 收进 `Platform/AdaptiveZoom.swift` 并把这条加进了 `check_lint.py`
    （`platform_branch`，命中即失败）。`#if canImport(...)` 是能力探测，不算。

21. **`Section("标题") { } footer: { }` 这个形态不存在**（M03P16 首验编译错）：
    带 header / footer 的 `Section` 只能写成 `Section { 内容 } header: { ... } footer: { ... }` ——
    标题从 `Section("…")` 的参数挪进 `header:` 闭包。本地闸门抓不到 API 形状，只能靠人记
    （写法照 `InterfaceManagementView` / `SettingsView` 里已有的那几处）。

22. **给「多处构造」的视图加参数，先 grep 全部调用点 + 想两件事**（M03P22 / M07d10 首验都红在
    这上头）：M03P22 给 `ParsePlaybackView` 加两个必填参数，漏了 `SitePlayEpisodeView` 里那个；
    M07d10 给 `PlaybackView` 加 `onVerticalSwipe`（**可选**参数）又踩了两条：
    - **实参顺序必须跟声明一致**：参数插在中间时，调用点里排在它后面的实参要往前挪，
      否则报 `argument 'x' must precede argument 'y'`（可选参数也照管）；
    - **public init 的参数类型必须 public**：闭包参数里那个 `PlaybackSwipeAction` 原先是 internal，
      于是 `initializer cannot be declared public because its parameter uses an internal type`
      （`PlaybackLineSwitcher` / `PlaybackPlaylist` 当年 `public` 的理由就是这一条）。
    加参数之前 `grep -n "XxxView(" Packages` 看清调用点、顺手想一遍「谁要 import 它 / 它够不够 public」，
    这两类**本地闸门都抓不到**（不编译），Mac 上跑一次才看得见。

23. **「参数写好了、没人传」这种断线，编译和单测都抓不到**（M03P18）：`PlaybackView` 的
    `danmakuLines` / `danmakuDisplay` / `subtitleCues` / `subtitleDisplay` 四个参数从 M08h/M09f
    落地起就没被任何宿主传过 —— 编译过、单测全绿、上机才发现「怎么什么都不显示」。
    新建可选参数时多想一步：**谁负责传**，并且在文档里写清楚（这次是矩阵里「屏上效果待真机确认」
    一直挂着，把断线藏了很久）。

24. **「定义了但从没被调用」的停止 / 清理方法要当真**（M06o）：`stopLocalServer()` 从 M6 落地起
    一个调用方都没有，而 `ensureLocalServer()` 注释里写的「回到前台需要再 start 一次」也从没接线 ——
    同一个坑的两种形态：**意愿写在注释里，不等于接上了**。审计孤儿方法时问两句：
    「它本该被谁调」+「注释里承诺的事谁在做」（与 22 条同一课）。

25. **留口的「不做」理由会过期**（M07d10）：M07d-3 写「直播页手势换台不做 —— 播放页是系统
    `AVKit.VideoPlayer`，手势面归它」，半年后自绘内核（M03P6 / M03P12）上来这句话就不成立了 ——
    开工前把留口原文读一遍，别拿旧结论当挡箭牌；写完「不做」时顺手记下**它成立的前提**，
    前提变了就该回来把这一条划掉。
