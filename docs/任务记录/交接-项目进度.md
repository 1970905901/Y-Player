## 工作方式（这套被证明有效，建议沿用）

- **本机没有 Swift 编译器、没有 swiftformat / swiftlint、没有 node** —— 一切以 CI 为准。
- 提交前跑：`check_braces` / `check_lint` / `audit_duplicate_types`（都在 `Tools/out/`）。
- **闸门**：检查不过不提交。红着提交纠正过两次。
- **CI 日志怎么拉**（本机有 `gh` 但未登录，用 token + curl）：
  ```
  curl.exe -sL -H "Authorization: Bearer <TOKEN>" -H "User-Agent: yplayer-local" `
    -H "Accept: application/vnd.github+json" `
    "https://api.github.com/repos/1970905901/Y-Player/actions/jobs/<JOB_ID>/logs" -o Tools/out/x.log
  ```
  作业 id 从 `…/commits/<SHA>/check-runs` 拿；**注意是 `/actions/jobs/<id>/logs`，
  不是 check-run 的 `/logs`**（后者只回 106 字节的错误页）。
- 每笔提交一个主题；消息里写清「为什么这么做」和「**故意没做什么**」（后者最省下一个人的时间）。

## 踩过的坑（别重复）

1. **被控制台编码吃掉的中文不要猜**。我猜过两次中文原文去做替换，两次都 `text not found`。
   要改就只用 ASCII 锚点，或先用 `Tools/out/show_ascii.py`（非 ASCII 打 `?` + 行号）看结构。
2. **文档改动一律追加**。拿既有行当替换锚点，会把那一行吃掉 —— 我吞掉过两次 `## 已知风险` 标题。
   确实要改既有内容时，被保留的锚点行**必须**出现在 `new_text` 里。
3. **批量替换先断言命中数**。这条拦下过三次；其中一次正则命中 6 行、把 5 个用例的语义悄悄改秃。
4. **宏里别放复杂表达式**：`#expect` / `#require` 里带闭包、`async`、`try` 容易展开失败 ——
   先绑成局部 `let` 再断言（`.swiftformat` 里 `preferKeyPath` 被关掉就是这个原因）。
5. **同文件既有约定是权威**。我照别处抄了 `@Sendable` 到 `PlaybackView` 的闭包上，
   而那个文件的既有闭包 `onDanmaku` 根本不带 —— 复制粘贴前先看本文件的邻居。
6. **测试没跑过 = 没测过**。M10/M11 那批「从未编译」的代码里躺着 4 个真 bug + 一堆接口过期。
7. **写测试桩前先找本包有没有现成的**（撞名过一次；两个桩 API 不同，7 个调用点全废）。
8. 沿用既有约定：迁移**只追加**不改 v1；`running` 恢复降级 `waiting`；代理地址改写收口一处。
