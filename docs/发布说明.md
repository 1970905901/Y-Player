# YPlayer v1.0.0（第一版正式版）

CatVod 生态的 **Apple 平台影音壳**（Swift）：iOS/iPadOS 15+、macOS 13+。
本仓库**不内置、不提供、不分发任何影视内容、接口源或直播源** —— 所有接口由使用者自行添加，
仅供技术学习与研究使用。

> 这份文件就是 GitHub Release 的正文（`build.yml` 的 release 作业用 `body_path` 读它）。
> 发下一版时**先改这里**，再打 tag。

## 下载与安装

| 平台 | 产物 | 安装 |
| --- | --- | --- |
| iOS / iPadOS | `YPlayer-unsigned.ipa` | **未签名**，需自行侧载并重签：Sideloadly / AltStore / TrollStore 等（免费 Apple ID 证书 7 天有效，开发者账号 1 年） |
| macOS 13+ | `YPlayer-macOS-unsigned.zip` | 解压后首次打开需**右键 → 打开**；或 `xattr -dr com.apple.quarantine YPlayer.app` |

详细步骤（含「从 Windows 侧载到 iPhone」）见
[构建与分发](https://github.com/1970905901/Y-Player/blob/main/docs/构建与分发.md)。

## 这版有什么

- **源**：`type 0/1/2/4`（XML / JSON CMS、HTTP+base64 `ext`）与 `type 3`（CatSpider HTTP、JS Spider）。
  **js2p（JS 源）**：`index.js` + `index.js.md5` 形态 —— 下载 → MD5 增量校验 → 内嵌 Node 运行 →
  本机 HTTP 服务 → 按 CatSpider 路由调用（iOS 用随包 libnode，macOS 用 node 可执行文件）。
- **界面**：发现页（首页 / 分类 / 站点面板：分组条与排序、改名、搜索、规则管理）、搜索页、详情页
  （线路 / 选集 / 收藏 / 下载）、追剧页、直播页、设置页（源地址 / 首页展示方式 / 播放 / 数据 / 弹幕 / 字幕）。
- **播放内核（三选一，设置里手动选，运行时不自动降级）**：
  - `system`：`AVPlayer`，兼容性最好；
  - `mpv`：`libmpv`（MoltenVK → Metal），格式与多音轨 / 字幕覆盖最全；
  - `ffmpeg`：自研 FFmpeg 内核（硬解 / 软解手动选、HDR 那条走硬解；逐帧步进、音量增益、
    播放信息里的编码 / 色彩 / 两侧丢帧都是它）。
- **播放页**：倍速（滑杆 + 预设 + 长按临时加速）、画面比例（按片记忆）、双指缩放、
  上滑 / 下滑切集、单击显隐控制条（播放中自动收起）、锁屏防误触、逐帧步进、音量增益（1.0–2.0）、
  换线路、片头 / 片尾标记、单集循环、选集抽屉、弹幕（搜索 / 显示设置 / 换一条 / 换关键词重搜）、
  字幕（外挂 + 内嵌文本轨）、**播放信息**（编码 / 帧率 / 色彩 / 输出像素格式与色彩标签 / 丢帧）。
- **直播**：底部 Tab；分组（含加密分组解锁）、频道「收藏」分组、EPG 节目单（落盘缓存、跟着整分钟走）、
  多线路、上次观看、纵甩换台、开机自启。
- **下载**：HLS 清单展开（AES-128 / 字节范围片段）、直链流式落盘 + Range 续下、暂停 / 继续、
  整部逐集换地址、下载列表实时进度、下好的那一集**直接播本地文件**。
- **本地代理**（设置 → 播放，默认开）：HLS 主清单 / 子清单 / 分片 / 密钥的 header 注入、
  `/m3u8` 清单改写与**广告清理**（`hlsRules` 规则开关）、大文件「边下边发」、落盘配额与自动清理；
  开关关了服务当场停。
- **其它**：观看进度 / 历史 / 收藏（落库）、一键诊断报告（含最近一次播放的内核读数）、
  接口缓存管理、本机服务与 Node 宿主状态在设置里如实展示。

逐字段的支持状态见
[协议兼容矩阵](https://github.com/1970905901/Y-Player/blob/main/docs/协议兼容矩阵.md)。

## 已知限制（本版没做）

### 明确不做（拍过板，不会再做）

- **JVM / Python 源**：`csp_*.jar`（type 2/3 的 JAR 形态）与 `.py` 需要 JVM / CPython，不做；
  界面上会明确给出原因并禁用。
- **直播 `core` 内核（tvbus）**：非空的 `core.type` 直接拒绝并说明（一个请求都不发）。
- **Widevine / PlayReady**：Apple 平台没有对应 CDM；`SAMPLE-AES` 加密下载同样如实拒绝
  （要 CENC 取样解密）。
- **网页首页（WebHome）与壁纸**：字段保留（保证配置能解码），不做形态。
- **跨设备同步（iCloud）**：没有开发者账号 ⇒ 起不了 iCloud 容器，设置页不出现这一区。
- **消息回宿主（`messageToDart` / `POST /msg`）**：bundle 自己会降级，没必要起那条通道。
- **KSPlayer / VLC 两条播放内核路线**：已评估否掉，不重开。
- 接口里的 `logo` / `notice` 字段：解析得进模型（有值会在「接口管理 → 告警」里如实提示），
  不做界面消费；`doh` / `hosts` 覆盖是**平台缺口**（`URLSession` 没有 DNS 钩子），
  要真支持得自建连接层。

### 以后可能做（记着，别当成漏了）

- **DRM ClearKey**（矩阵里 ⚠️ 待实现）：与 `SAMPLE-AES` 是同一块 CENC 解密，做完能补上加密那一档。
- **本地服务其余路由**（`/action` `/cache` `/file` `/parse` `/spider`）：都是「外部客户端」族的入口
  （局域网网页管理台 / 推送 / 缓存读写 / Spider HTTP 桥）；本机服务**只监听回环**，
  现无调用方 —— 等做「局域网推送 / 投屏」（M9+）时再回来。
- **组规则的 AI 生成**：候选顺序里留了那一档（内置 → 接口 → AI 留白 → 用户）。
- **直链断点续下**：HLS 有续下账目，直链目前整份重下。
- **播放器零碎**：逐帧**后退**、音量增益落盘 / 按片记忆、换轨淡入淡出、内嵌字幕带语言 / 标题。
- **字幕 / 软解边角**：位图轨（PGS / DVD）与 ASS 样式（libass）不做；软解不做色彩转换 / tone mapping，
  10bit 的 4:2:2 / 4:4:4 不做。
- **代理两条尾巴的剩余**：落盘文件不复用（同一 Range 再请求会重落一份）、配额固定 1 GiB
  （不按盘剩余空间算）。

更细的「为什么不做 / 前提是什么」分别在
